## 三、排盘层

### 3.1 起局方法：拆补法（推荐）

**来源**：善天道精华 p4 明确推荐；应用学案例一律采用；日志 6/8 修正教训

**规则**：按节气日数分段定上中下三元，一进交接时辰即用该节气之局，不用符头法。

⚠️ **警示**：置闰法的符头规则（甲己定元）**不可混用于拆补法**。《预测学》P66-68 内部自相矛盾，原文证据（8/7收尾复查再次确认）：
- P67："拆补法仍然按上中下三元，仍然采用日干支甲己为符头"
- P68："只要一进入交接时辰就用这个节气规定之局"

两规则在边界日期（如癸丑日）会产生不同结果。裁决：用日数分段法，以在线排盘为准。

### 3.2 上中下元符头规则（仅置闰法使用）

```
上元第一天日支：子午卯酉 → 符头：甲子、甲午、己卯、己酉
中元第一天日支：寅申巳亥 → 符头：甲寅、甲申、己巳、己亥
下元第一天日支：辰戌丑未 → 符头：甲辰、甲戌、己丑、己未
超神 = 上元符头在前，节气在后
接气 = 节气在前，上元符头在后
置闰 = 上元符头超过节气九天
```

- 阳遁顺排、阴遁逆排：戊己庚辛壬癸丁丙乙

### 5.5 应期确定

#### 五步程序化检查法（幺学声体系，6/8升级）
1. 看空亡：逢空→冲空或填空之时
2. 看入墓：入墓→冲墓之时
3. 看值使落宫数字：结合内外盘取数
4. 看马星：冲动对宫或本宫之时
5. 综合判断

#### 三步曲（实战裁决，6/8 LG-01修正）
为什么空 → 空什么 → 什么冲填。**每步不可省略**，禁止跳步直推应期。

#### 三法并用（善天道高级班 p9-10）
1. 逢空逢墓：被冲空/填空之时
2. 值使落宫数字：内盘取小数（快/近/少），外盘取大数（慢/远/多）
3. 马星冲动：冲动对宫或本宫之时

#### 第六法：合处逢冲（《最新实例解析》p084-085，8/8补充）
用神宫与其他宫成六合关系时，应期在**合局被冲之时**（如子丑合→未时/未年月冲开）。另两要点：①**旺衰法**：用神旺相应期快、休囚慢；②多法指向同一时段时可靠性更高；本书直言"应期最难，初学者能断大致范围即可"——与实战"不硬求精确"守则呼应。

#### 量化断法（善天道独有，高级班案例提炼）
金额/分数/天数 = 用神落宫数字 + 值使门数字 + 相关用神数字，结合阴阳局内外盘取大小，逢空打折。案例精度：高考断680-700实际688；标价断5000万应验。⚠️未独立验证

### 5.9 情境推演法 v0.1（⚠️自创假设框架，整体未验证）

> 性质：个人渐进式理论创新，解决"背书式解盘"痛点。整合已有体系，不推翻。须逐条实战验证后方可采信。完整版见 F:\奇门遁甲\修炼日志\理论创新_情境推演法_v0.1.md

**五层推演结构**：
```
第0层 定事定位（先问清楚再碰盘面；四分法强制分类）
第1层 能量状态前置（旺相休囚死/四害，先算能量再谈象意）
第2层 取用神（按分类对应取神）
第3层 情境转译（核心创新层）
第4层 加权裁决（优先级+凶格计分+信号加权+主客）
输出：结论+应期+不确定性等级+📖/🧠来源标注
```

**分离标注法（最重要的单条创新）**：
- 📖 = 直接来自书本断语；🧠 = 我的情境转译/推演
- 每个符号先写📖层再写🧠层；🧠必须给出推理链
- 📖与🧠冲突时以🧠为准但保留📖原文供复盘
- 目的：防止把推演伪装成书证，也防止把书证当圣旨

**情境转译三问**（🧠转译前强制回答）：
1. 问事体：该符号在所问之事里扮演什么角色？
2. 问正反面：正/负象意哪个贴合本情境？
3. 问能量：当前能量状态支持正面还是负面发挥？

**能量打折规则**（自创，⚠️待验证）：
- 旺相：断语全额生效；休囚：吉凶减半
- **旺为库衰为墓**：墓库同见时，月令有气作"库"（储能待用），无气作"墓"（困顿）
- **门迫吉凶反转检查**：凶门被迫时先问是否"必要之恶"（惊门之于反省、伤门之于追讨），是则不单断凶

**推演链要求**：象意→情境映射→行动含义，至少推两层；跳步即标记"推理不完整"。

**待验证组件**：分离标注法/三问/能量打折/旺库衰墓/门迫反转/四分法前置分类——每项≥3次独立真验证才可升级为已验证规则。

### 13.2 关键发现：空间精度天花板（新方法论瓶颈）

奇门天气预测的**空间分辨能力**受限于占问范围与盘面分辨率的不匹配：
1. 占问"广东天气"（300km×400km大范围）→ 盘面信号无法区分内部区域
2. 实际结果分区差异明显（珠三角晴/粤北雨/粤东雨），但预测只给出笼统结论
3. 书上天气预测法只说"天英=晴、天蓬=雨"，未说九宫对应空间区域

**结论**：天气预测法在**大范围定性**（全省晴/雨趋势）上可用，但**空间精度**受限于占问粒度。这是体系本身的天花板，不是断法错误。

**改进方向**（待验证）：
- 若占问"广州明天天气"（单一城市），盘面信号是否更精确？
- 九宫拟象法能否用于天气预测的空间分区（如离=珠三角、坎=粤北）？
- 需至少3次前瞻验证才能初提为规则，当前样本=0

**此发现的意义**：首次识别出奇门预测的**空间精度天花板**，这是此前完全没想过的问题。不是"我没断对"，而是"体系本身在空间维度上有盲区"。
