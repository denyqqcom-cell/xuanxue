### 第六步：⚖️ 看生克（用神宫与相关宫横向关系）
> 分析宫与宫之间的五行生克关系

**核心判断原则：**
```
门克宫 → "迫"（凶）
宫克门 → "制"（吉事不成、凶事也不起）
门生宫 → "和"（吉）
宫生门 → "义"（吉，需付出）
门宫比和 → 中平
```

**主客判断：**
| 条件 | 主/客 | 动静 |
|------|-------|------|
| 五阳干（甲乙丙丁戊） | 利客 | 先动 |
| 五阴干（己庚辛壬癸） | 利主 | 后动 |
| 伏吟局 | 利主 | 安静 |
| 反吟局 | 利客 | 行动 |
| 天盘生地盘 | 利主 | 静 |
| 地盘生天盘 | 利客 | 动 |

- 善天道高级班 → 主客动静完整判断
- 《奇门遁甲应用学》第5章 → 预测判断方法

### 第七步：📅 定应期
> 确定事件发生的时间

**定应期三法：**
| 方法 | 要点 |
|------|------|
| **空墓法** | 逢空逢墓之地支，被冲空或填空时为应期 |
| **值使法** | 看值使门落宫有几个数字，结合内外盘确定 |
| **马星法** | 冲动对宫或冲动本宫时为应期 |

**内外盘判断应期远近：**
- 内盘（1,3,4,9）→ 快、近、短
- 外盘（2,6,7,8）→ 慢、远、长

- 《奇门遁甲应用学》第6章 → 定应期方法
- 善天道高级班 → 应期确定三法
