## 二、财运类案例

### 案例要点

> 《奇门遁甲最新实例解析》  
> *"求财预测：以生门为用神，戊为资本，结合落宫生克判断财运吉凶。"

**分析要素**：
| 要素 | 内容 |
|------|------|
| 主用神 | 生门 |
| 辅助用神 | 戊（资本）、丙（机遇） |
| 忌讳组合 | 庚+甲、击刑、入墓 |
| 方向判断 | 生门落宫方向 |
| 时机判断 | 值使落宫/马星 |

**案例参考**：
> 曾子南《三元奇门遁甲讲义上》  
> *"求财案例：生门落艮八宫，与日干落宫比和，利求财。戊落离九宫生助生门，当年财运亨通。"

## 三、婚姻类案例

### 案例要点

> 《奇门遁甲应用学》佚名·下编·第二章  
> *"婚姻预测：以六合、乙、庚为用神。乙为女，庚为男。以其落宫生克关系判断婚姻吉凶。"

**分析要素**：
| 要素 | 内容 |
|------|------|
| 主用神 | 六合、乙、庚 |
| 关系判断 | 乙庚落宫生克 |
| 吉凶标志 | 六合+吉门+吉星 |
| 凶险标志 | 庚+凶门+玄武 |
| 第三者 | 丙（男用丙）、丁（女用丁） |

**曾子南讲义案例**：
> 曾子南《三元奇门遁甲讲义中》  
> *"婚姻案例：乙落坤二宫，庚落乾六宫，宫与宫相生，婚姻和美。庚+玄武则防第三者介入。"

## 八、案例学习注意事项

| 注意事项 | 说明 |
|----------|------|
| 案例非绝对 | 预测有约八成准确率，非百分百 |
| 因人而异 | 同样的盘，不同解读有差异 |
| 因时而异 | 时辰不同，盘面不同 |
| 综合判断 | 不可偏执一端 |
| 积累经验 | 多看案例，多实践 |

## 十、《奇门直断》实战直断技法

### 10.1 单位状况直断

**文献出处**：
> 《奇门直断》杜新会·第一章·单位状况  
> *"奇门直断是我根据二十多年来研究奇门遁甲所得规律，经过实践反复验证总结的实战技巧。"*

| 判断事项 | 直断方法 |
|----------|----------|
| **单位规模** | 开门落二、八宫且宫中格局旺，遇吉神吉格，开门受生，单位规模大；格局弱则规模小 |
| **团队精神** | 乙、丙、丁三奇入墓，则代表同事不和睦，团队精神差 |
| **同行竞争** | 月干代表同行，遇庚加庚或月干临伤门主同行竞争激烈 |
| **内部调整** | 开门遇击刑或刑格、逢冲，说明工作单位会整合、改组、机构会变化 |
| **行业困难** | 值符为大环境，逢庚、击刑、入墓，行业困难 |
| **意见分歧** | 开门加庚意见不统一，有分歧 |
| **员工能干** | 日宫中格局旺，临开门、生门或伤门、九天，则员工能干，工作能胜任 |
| **事情未定** | 开门加己，事情还没最终敲定 |
| **上下级关系** | 太岁生日干或值符生日干，上级领导支持；月干、时干生日干为同行或下级拥护 |

### 10.2 工作状况直断

**文献出处**：
> 《奇门直断》杜新会·第二章·工作状况

| 判断事项 | 直断方法 |
|----------|----------|
| **领导能力** | 凡乘值符者，有一定的组织能力，或曾当过领导 |
| **升职快慢** | 开门生日干，值符旺生、月干旺生、时干旺生、直使旺生，日干旺相均主快 |
| **升职不吉** | 伏吟局一般不能升职，强升则不吉 |
| **单位领导** | 日干上乘值符，则在单位当过领导；用神落乾宫一般在领导层任过职 |
| **两个工作** | 开门乘六合，有两个工作或曾经有过两个以上工作 |
| **领导正副** | 用神乘值符者，落四正宫为正职，落四维宫为副职或委员 |
| **工作与宫** | 乾宫应在大城市、指挥机关；坎宫应从事与水有关工作；艮宫应与银行和食品业有关 |
| **更换职场** | 开门宫中有庚加戊、戊加庚、庚加壬、壬加庚，九星宫中逢冲、临马星格局时易更换 |
| **近处调动** | 开加乙，测调动则为内部调动，伏吟也是内部调动 |
| **远方调动** | 开门宫中庚加壬调动远，用神上乘九天或落外盘或四维宫也主调动远 |
| **辞职** | 日干击刑且克开门时，为求测人主动提出辞职 |

### 10.3 产品销售直断

**文献出处**：
> 《奇门直断》杜新会·第三章

| 判断事项 | 直断方法 |
|----------|----------|
| **产品滞销** | 时干生日干，产品卖不出，逢庚有困难 |
| **产品畅销** | 时干克日干，产品好卖出 |
| **产品销路** | 时干玉女守门，利在本地销售；时干乘九天，主销往外地 |
| **高级产品** | 时干宫中乘值符为高级产品，若再有三奇和三吉门，产品质量高级 |
| **产品质量** | 时干宫中符号弱，说明产品质量一般 |
| **假冒伪劣** | 玄武，必定是假冒伪劣产品 |

### 10.4 婚姻直断

## 十一、《日家奇门运筹秘法》补充

### 11.1 日家奇门特点

**文献出处**：
> 《日家奇门运筹秘法》·序言  
> *"日家奇门以日为周期，不同于时家奇门以时为周期。日家奇门更侧重于择日、运筹。"*

### 11.2 日家奇门应用

| 应用领域 | 说明 |
|----------|------|
| **择日** | 选择吉日开业、婚嫁、出行、动土等 |
| **运筹** | 根据日盘格局制定策略 |
| **决策** | 大事用日家，小事用时家 |
