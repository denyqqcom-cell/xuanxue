# 空、墓、刑、迫：状态特征识别版

> **上位约束**：`奇门/CURRENT_METHOD_CONSTRAINTS.md` 与 `qimen-overview`。
>
> 本技能不再把空、墓、刑、迫定义成“四大凶兆”，也不执行“吉自动打折、凶自动加重”。

## 一、先纠正一个历史概念混用

旧知识中曾把：

`空亡 / 入墓 / 击刑 / 门迫`

称为“四害”，同时把善天道讲义中的“四个避开”当作同一来源依据。

但项目 2026-08-07 自查已发现：**“盘面状态检查项”与“择时/行动避开项”不是同一概念。**

因此当前文件只负责前者的结构识别；五不遇时、时干入墓、六仪击刑等若作为“避开条件”，应按具体 source/method family 单独冻结，不能把两个名词混成一个规则包。

| 旬 | 空亡地支 |

| 甲子旬 | 戌、亥 |
| 甲戌旬 | 申、酉 |

| 甲辰旬 | 寅、卯 |
| 甲寅旬 | 子、丑 |

这张表用于**识别旬空**，不直接提供吉凶。

### 2.2 当前解释纪律

传统书中可见“事不实、落空、虚、待填实”等多种断语；项目历史又曾从“逢空偏凶”过度纠偏为“逢空=方向待定”。两者都不再作为全局真理。

当前步骤：

1. 谁/什么逢空？
2. 空的是哪个地支/宫位？
3. 当前方法族是否把空亡列入 Eligible Feature Set？
4. 本题可能对应哪些竞争解释？
5. 什么现实结果能区分“延迟 / 落空 / 暂缺 / 脱离 / 非关键”等分支？

### 2.3 冲空 / 填空

部分传统应期体系使用冲空、填空作为时间候选。

这里仅记录结构；具体应期必须转到 `qimen-yingqi`，先冻结 timing method，再给时间窗口。禁止结果出来后看到某个冲/填日期接近实际就补算命中。

### 3.2 历史文件勘误

旧版 `qimen-sihai` 曾出现内部不一致，例如：

- 表内把辛写成“墓戌”，而 `qimen-basics` 十二状态表为辛墓辰；
- 歌诀文字把庚壬并在同一墓位，但表内又给庚、壬不同位置；
- 这类混写会导致验证标准本身不稳定。

当前处理：

- 上表作为**当前项目 structural baseline**；
- 若梁湘润、善天道或其他流派给出不同入墓体系，不静默改表，而是记录 `SCHOOL/CONTEXT CONFLICT`；
- 在具体预测中必须写明采用哪套墓位定义。

### 3.3 入墓不自动等于凶

“收藏、受限、潜伏、停滞、结束、入库”等都是来源或情境候选。

不得使用：

`用神入墓 -> 必败`

或：

`凶神入墓 -> 凶必减`

作为无条件公式。

先看角色、问题域、旺衰语境、相关宫关系，再形成竞争解释。

| 壬（甲辰） | 巽4 | 辰辰自刑 |
| 癸（甲寅） | 巽4 | 寅巳刑语境 |

### 4.2 当前用法

传统资料常给予击刑强烈凶性评价。当前项目保留这一 SOURCE 事实，但实际推演只先记录：

- 哪个六仪发生击刑；
- 它代表哪个 Role；
- 是否在当前 Method Family 中是主特征；
- 是否有相反关系或限制条件；
- 该传统评价有无前瞻经验支持。

不得仅凭“击刑”直接输出伤残、牢狱、重大灾祸等高风险现实结论。

## 五、门迫 / 门宫关系：关系结构，不是固定吉凶器

### 5.1 五种关系

| 关系 | 结构 |
|---|---|
| 门克宫 | 门五行克宫五行，传统称“迫” |
| 宫克门 | 宫五行克门五行，常称“制” |
| 门生宫 | 门生宫 |
| 宫生门 | 宫生门 |
| 门宫比和 | 同五行 |

旧版直接写：

- 门克宫=大凶；
- 门生宫=吉；
- 宫生门=吉但付出；
- 凶门被迫更凶。

这些现降级为传统解释候选。

当前推演要问：

- “门”在本题代表什么？
- “宫”是环境、对象还是空间载体？
- 生克方向在当前问题里是支持、消耗、控制还是压力？
- 所谓“吉门/凶门”的预设是否与现实任务一致？

例如伤门在医疗手术、讨债、竞争等情境中未必与“伤害”同义；开门在关闭、保密、收缩任务中也未必天然有利。

## 六、五不遇时：另列为来源规则，不混进“四害”

常见定义是：**时干克日干，且阴阳同性相克**。

对应干关系：

`甲-庚 / 乙-辛 / 丙-壬 / 丁-癸 / 戊-甲 / 己-乙 / 庚-丙 / 辛-丁 / 壬-戊 / 癸-己`

旧资料常称其为强凶择时条件。

当前规则：

- 若 Method Family 明确使用五不遇时，则在预测前冻结；
- 不因出现五不遇时就自动推翻全部其他信息；
- 具体到“某日哪些时辰构成”时必须按真实时辰干支展开，不能只凭记忆填标准值；
- 项目曾发生验证脚本标准值凭记忆写错，因此记忆只能做线索，不能做验证证据。

## 七、“真空 / 假空”等二级规则

部分来源根据旺衰、生克等再区分所谓真空、假空。

这种规则属于**二级模型**：它不是旬空本身的结构，而是对旬空作用方式的再解释。

因此使用前必须写：

```text
source/method_family:
base_empty_structure:
secondary_rule:
applicability:
empirical_support:
```

不得把某书的“真空/假空”定义混进另一流派后仍称为同一方法。

## 九、红线

- 不再称空、墓、刑、迫为统一“四大凶兆”；
- 不再使用固定“折扣”语义；
- 不把空亡固定改写成“方向待定”；
- 不把入墓固定改写成“事情受阻”；
- 不把击刑直接翻译成现实伤灾/牢狱；
- 不把门克宫直接判大凶；
- 不混用不同流派的墓位、空亡二级解释或择时规则；
- 发现来源内部表格/歌诀不一致时标 `SOURCE_INCONSISTENCY`，不得靠记忆静默修正。
