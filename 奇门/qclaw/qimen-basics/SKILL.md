# 奇门基础：结构层与传统象意分离版

> **上位约束**：`奇门/CURRENT_METHOD_CONSTRAINTS.md`。
>
> 本文件优先回答“盘的结构是什么”，不负责把传统象意直接变成现实事实。

## 一、先区分三类内容

### A. 结构/历法约定

例如：

- 五行生克关系；
- 十天干、十二地支的阴阳五行；
- 六十甲子组合规律；
- 六甲旬首遁六仪；
- 后天九宫五行方位；
- 旬空如何计算。

这类内容可作为排盘与结构识别基础，但仍须注意不同术数流派可能有附加规则。

### B. 传统术数模型

例如：

- 天干合化；
- 十二长生；
- 地支刑冲合害；
- 八神、九星、八门类象；
- 内外盘快慢；
- “天时/地利/人和/神助/格局”等解释框架。

这些是传统模型或某书方法，不自动等于经验事实。

### C. 象意与现实推断

例如：

- “某干=丈夫/罪人/医生”；
- “沐浴=外遇”；
- “白虎=车祸死亡”；
- “相刑=疾病牢狱”；
- “某合=风流好色/背信弃义”。

这些只能标 `SOURCE` 或 `CANDIDATE`，必须经 Role Map、情境与经验支持后才可进入具体推断。

## 二、阴阳五行

### 2.1 五行基本关系

**相生**：

`木 → 火 → 土 → 金 → 水 → 木`

**相克**：

`木克土、土克水、水克火、火克金、金克木`

这是后续宫位、干支五行关系的基础。不得再把九宫数字顺序或其他序列误写成五行相生链。

### 2.2 常见传统对应

| 五行 | 方位 | 季节 | 色 | 常见传统脏腑对应 |
|---|---|---|---|---|
| 木 | 东 | 春 | 青/绿 | 肝、胆 |
| 火 | 南 | 夏 | 赤/红 | 心、小肠 |
| 土 | 中 | 四季/季末 | 黄 | 脾、胃 |
| 金 | 西 | 秋 | 白 | 肺、大肠 |
| 水 | 北 | 冬 | 黑 | 肾、膀胱 |

“脏腑对应”属于传统类象，不是现代医学因果模型，也不能据此做诊断。

### 2.3 旺相休囚死

传统五行季令常用：

`当令者旺，我生者相，生我者休，克我者囚，我克者死`

当前项目把旺衰当作候选状态 feature，不使用“旺=全额、休囚=减半”等固定系数，也不从旺衰单独推出吉凶。

## 三、十天干

### 3.1 基础阴阳五行

| 天干 | 阴阳 | 五行 | 常见方位 |
|---|---|---|---|
| 甲 | 阳 | 木 | 东 |
| 乙 | 阴 | 木 | 东 |
| 丙 | 阳 | 火 | 南 |
| 丁 | 阴 | 火 | 南 |
| 戊 | 阳 | 土 | 中 |
| 己 | 阴 | 土 | 中 |
| 庚 | 阳 | 金 | 西 |
| 辛 | 阴 | 金 | 西 |
| 壬 | 阳 | 水 | 北 |
| 癸 | 阴 | 水 | 北 |

**普通天干阴阳分组**：

- 阳干：甲、丙、戊、庚、壬；
- 阴干：乙、丁、己、辛、癸。

这一点必须与部分奇门资料中的“前五干/后五干主客分组”分开，后者不是基础干支阴阳分类。

### 3.2 旧技能的一处基础逻辑纠偏

旧版曾把天干相生写成仅有：

`甲生丁、乙生丙、丙生己……`

并标“阴生阳、阳生阴”；又把相克写成“阳克阳、阴克阴”。

若把这些表述理解为**天干生克的完整规则**，是不成立的。

基础生克首先由五行决定：木能生火、火能生土、土能生金、金能生水、水能生木；木能克土等。阴阳可在具体传统理论中进一步区分作用方式，但不能把同五行关系中另一种阴阳组合直接排除。

因此当前文件不再把“异性才生、同性才克”写成总规则。

### 3.3 天干相冲

奇门传统常列四冲：

`甲庚、乙辛、丙壬、丁癸`

它反映木金、水火的对立组合。是否直接用于某一 Method Family，需反馈前冻结。

### 3.4 天干五合

| 五合 | 传统化气 |
|---|---|
| 甲己 | 土 |
| 乙庚 | 金 |
| 丙辛 | 水 |
| 丁壬 | 木 |
| 戊癸 | 火 |

“合”是传统结构；“化”是否成立，在命理/术数传统中还涉及条件，不应看到两干同现就自动视为已经化成某五行。

旧资料还使用“中正之合、仁义之合、威制/权威之合、淫慝/淫荡之合、无情之合”等古代术语，并进一步映射人格、婚恋与道德评价。当前仅保留为 SOURCE 术语，不据此直接判断真实人物的品格、忠诚或性行为。

### 3.5 奇门天干类象（SOURCE 候选）

不同资料常见：

| 干 | 常见奇门类象候选 |
|---|---|
| 甲 | 首领、主帅、核心 |
| 乙 | 日奇、女性、医生、柔曲 |
| 丙 | 月奇、权威、火、显耀 |
| 丁 | 星奇、灯光、精细、女性 |
| 戊 | 资本、钱财、土地/房产 |
| 己 | 地户、策划、低处/地下 |
| 庚 | 阻隔、武力、丈夫/竞争者等 |
| 辛 | 错误、刑罚、金属细物等 |
| 壬 | 流动、水、运输等 |
| 癸 | 隐藏、水、足等 |

这张表只说明传统文献会怎样取象。具体人物/事项角色由 `qimen-yongshen` 的 Role Map Freeze 决定。

## 四、十二长生：传统状态模型

当前项目沿用的一套结构表：

| 天干 | 长生 | 帝旺 | 死 | 墓 |
|---|---|---|---|---|
| 甲 | 亥 | 卯 | 午 | 未 |
| 乙 | 午 | 寅 | 亥 | 戌 |
| 丙、戊 | 寅 | 午 | 酉 | 戌 |
| 丁、己 | 酉 | 巳 | 寅 | 丑 |
| 庚 | 巳 | 酉 | 子 | 丑 |
| 辛 | 子 | 申 | 巳 | 辰 |
| 壬 | 申 | 子 | 卯 | 辰 |
| 癸 | 卯 | 亥 | 申 | 未 |

传统运行序列：

`长生 → 沐浴 → 冠带 → 临官 → 帝旺 → 衰 → 病 → 死 → 墓 → 绝 → 胎 → 养`

### 使用边界

旧版曾把阶段直接翻译为：

- 沐浴=桃花/外遇；
- 临官=事业兴旺；
- 帝旺=老年旺极而折；
- 病=身体不佳；
- 死墓绝=难以自拔。

这些是传统象意延伸，不是阶段名称本身的结构事实，更不是医学或现实必然结果。当前只作 SOURCE/CANDIDATE。

“旺为库、衰为墓”等说法同样属于特定解释规则，需要单独保存适用域和来源。

## 五、部分奇门资料的“前五/后五干”主客规则

历史资料中出现：

- 甲乙丙丁戊 → 利客/先动；
- 己庚辛壬癸 → 利主/后动。

有资料把这两组称作“五阳/五阴”。为避免与基础天干阴阳混淆，当前项目统一称：

- `FIRST_FIVE_GROUP = 甲乙丙丁戊`
- `LAST_FIVE_GROUP = 己庚辛壬癸`

只有选择该 Method Family 时才应用。来源若原文确实使用“五阳/五阴”，保留原词并标 `TERMINOLOGY_CONFLICT`。

## 七、六十甲子与六旬

### 7.1 旧版“10×12=60种组合”的纠偏

不能把六十甲子解释成“10 个天干 × 12 个地支的所有组合”。完整笛卡尔积是 120 对，而传统干支纪序要求天干、地支**同步各前进一步**，并保持阴阳奇偶配对，因此 10 与 12 的序列在最小公倍数 60 后回到甲子，形成六十甲子。

也就是说：

`LCM(10,12) = 60`

而不是简单 `10×12=60`。

### 7.2 六甲旬首遁仪

| 旬首 | 遁仪 | 旬空 |
|---|---|---|
| 甲子 | 戊 | 戌亥 |
| 甲戌 | 己 | 申酉 |
| 甲申 | 庚 | 午未 |
| 甲午 | 辛 | 辰巳 |
| 甲辰 | 壬 | 寅卯 |
| 甲寅 | 癸 | 子丑 |

这是奇门起局与旬空识别的重要结构。

## 十一、“天时地利人和神助格局”是作者模型，不是科学分层

部分《奇门遁甲预测学》资料把成败归纳为：

- 九星=天时；
- 九宫=地利；
- 八门=人和；
- 八神=神助；
- 十干组合=格局。

这可用于理解该作者怎样组织信息层，但不因“五层结构完整”就获得经验有效性。

尤其“神助/神秘力量”属于传统术数概念，不能改写成已证实的物理因果因素。

---

## 十二、“物物一太极”是传统哲学框架

部分文献用“大太极/小太极”解释整体与部分关系。

当前项目可把它作为：

- 空间拟象的理论来源；
- “局部嵌套整体”式类比框架；
- 九宫拟象的思想背景。

但旧版举例“肝脏影响血液、血液影响心脏”等不能因为太极哲学而自动获得医学因果证明。真实生理关系须由医学证据支持。

## 十三、基础技能的输出纪律

查询基础知识时，优先输出：

```text
STRUCTURE:
SOURCE TRADITION:
CURRENT PROJECT CONSTRAINT:
```

例如问“白虎是什么”：

- STRUCTURE：八神之一；
- SOURCE TRADITION：传统常与强硬、伤害、武力等象意相联；
- CURRENT CONSTRAINT：不能仅凭白虎直接判断车祸、死亡或伤灾。

问“逢空怎么看”：基础技能只给旬空结构；解释转到 `qimen-sihai` 和具体 Method Family。

## 十四、当前已知基础层勘误清单

本版本至少修复/隔离以下旧问题：

1. 天干生克被错误缩成“异性才生、同性才克”的完整规则；
2. “10天干×12地支=60种组合”的数学/历法表述错误；
3. 善天道/幺学声语境中的“前五/后五主客组”与基础天干阴阳混名；
4. 阳遁内盘旧写 `1、3、4、9`；
5. 十二长生阶段被直接翻译成外遇、疾病、死亡等现实定论；
6. 地支刑冲合害被直接翻译成固定吉凶；
7. 八神类象被当成自动事件判断；
8. 传统人体类象被混同于医学事实；
9. “神助”类传统概念被写得像客观因果层。

后续梁湘润与其他源若对上述结构本身提出不同定义，按 source/school/context 建立冲突，不靠当前文件的确定语气压掉来源差异。
