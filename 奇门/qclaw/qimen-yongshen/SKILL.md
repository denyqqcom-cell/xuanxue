## 七、九星旺衰（与天干不同）

九星旺衰着眼于九星对地盘九宫的作用，与五行天干的旺衰不同。九星最多不起作用（废），绝对不会死去。

**歌诀**：
> 要识九星配五行，名随八卦考羲经。  
> 与我同行即为相，我生之月诚为旺。  
> 废于父母休于财，囚于鬼兮真不妄。

**九星旺衰含义**：
| 状态 | 含义 |
|------|------|
| 旺 | 我生之宫（星生宫），发挥作用最大 |
| 相 | 与我同行（比和宫），次旺 |
| 休 | 休于财（星克宫），休息 |
| 囚 | 囚于鬼（宫克星），被制约 |
| 废 | 废于父母（宫生星），如废物无用 |

**九星旺衰以落宫为主，兼看月令**。

## 八、求财预测用神体系（源自原典P138-P144）

> 来源：《奇门遁甲预测学》幺学声·第六章·求财预测  
> ⚠️ 注意：我之前25天一直跳过了此体系，用自己拼凑的简化版。7/1用完整方法后首次幅度准确。

### 8.1 投资求财核心用神

| 用神 | 代表 | 判断要点 |
|:----:|:-----|:---------|
| **日干** | 求测人（股市参与者） | 旺衰定自身状态 |
| **甲子戊** | 资本/本金 | 落宫旺衰定投资额，格局定运作状态 |
| **生门** | 利润/利息 | 落宫定利润大小，格局定获利方式 |
| **值符** | 求测方/放贷人 | 与天乙的生克关系定风险 |
| **天乙(地盘之星)** | 市场/借贷方 | 旬首所在宫的地盘星 |
| **开门** | 公司/大盘环境 | 旺衰定整体环境 |

### 8.2 核心判断逻辑

**第一判断**：生门与甲子戊的关系
| 关系 | 结论 |
|:----|:-----|
| 生门生甲子戊 | ✅ **必得利**——最吉判断 |
| 生门与甲子戊比和 | ✅ 中利 |
| 甲子戊生生门 | ⚠️ 增加资本仍可得利 |
| 生门克甲子戊 | ❌ **赔本**——最凶判断 |

**第二判断**：生门自身状态
- 生门旺相+吉星+吉格→即使生门克甲子戊，也可能有利润但变数大
- 生门休囚+凶星+凶格→利润极小

**第三判断**：值符与天乙的关系
| 关系 | 结论 |
|:----|:-----|
| 值符克天乙或天乙生值符 | ✅ 可放贷/投资，无风险 |
| 天乙克值符或值符生天乙 | ❌ 有风险不可借 |
| 生门与天乙同宫克值符 | ❌ 本息全损 |

**实操流程**：
```
① 查甲子戊落宫+格局 → 定资本状态
② 查生门落宫+格局 → 定利润状态
③ 生门生甲子戊？→ 必得利（核心判断）
④ 查值符-天乙关系 → 定风险大小
⑤ 查开门 → 定大盘环境方向
⑥ 综合判断 → 出结论
```
