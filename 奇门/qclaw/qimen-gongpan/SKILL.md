## 二、九星详解

### 2.1 九星旺相休囚（九星专用法则）

> **注意**：九星的旺相休囚与五行旺相休囚不同！

| 状态 | 定义 | 说明 |
|------|------|------|
| **旺** | 我生之月 | 对地盘宫影响力最大 |
| **相** | 与我同行之月 | 影响力次旺 |
| **废** | 月建生我（我生之月之前） | 不起作用 |
| **休** | 我克月建 | 不用发挥作用 |
| **囚** | 月建克我 | 虽被克制，仍在发挥作用 |

**举例**：天蓬（水），旺于初冬仲冬（亥子月），相于正、二月（寅卯月木生水）

**文献出处**：
> 《善天道-奇门遁甲讲义71页》第十章·九星详细解读  
> *"九星旺相休囚与五行旺相休囚不同，须按各自所属五行另行推演。"*

### 8.3 风水预测：十天干在风水中的象意（原典第十章）

> 来源：《奇门遁甲预测学》幺学声·第十章·P208-P210  
> 总纲：日干=人、时干=宅。时干生日干=无害，时干克日干=不利。

| 天干 | 风水对应 | 吉凶象意 |
|:----:|:---------|:---------|
| 甲 | 栋柱、大梁、水泥横梁、高大家具 | 冲克日干则横梁压顶 |
| 乙 | 檩条、床铺、窗户、低矮家具、花草 | 乙+辛/惊→床有响动；乙+壬癸→床下潮湿 |
| 丙 | 灶具、明火、烟囱、灯光 | 丙+丙+九天/景/白虎+冲克日干→火灾风险 |
| 丁 | 电子产品、电话、台灯、十字路、香火 | 丁+癸/壬→暖水瓶/水塔；旺地临死门→供奉神佛 |
| 戊 | 高地、房屋、大树、院墙、电线杆、桥梁 | 戊+庚辛→电线杆；戊+壬癸+天蓬→桥梁 |
| 己 | 阴沟、地户、天井、坟、园圃 | 旺地吉星→天井气好；己+己/辛+太阴/玄武→低矮潮湿 |
| 庚 | 道路、过道、铁路、屋脊、大型金属物 | 值使门临庚→门前大路；庚+辛→崎岖不平 |
| 辛 | 粮仓、门窗、锅碗瓢盆、电线杆、小路、死者骨骸 | 临阴星+太阴→可能为坟地 |
| 壬 | 河流、水路、沟渠 | - |
| 癸 | 阴沟、下水道、湿地 | 乙+壬/癸→床铺下面潮湿或有管道 |

**判断总纲**：
1. 时干生日干→风水无害，即使星门神格局不好
2. 时干克日干→风水不利，即使星门神格局再好
3. 生门+戊=阳宅；死门+己=阴宅
4. 生门落宫受制+凶神凶格克伤日干→对人不利
