# 定应期

> **核心定位**：解盘第七步，确定事情发生的时间节点  
> **核心原则**：应期是预测的最高境界，需综合多种方法  
> **文献来源**：幺学声《奇门遁甲预测学》第六章 + 善天道高级研修班讲义

## 一、定应期五步法（幺学声体系，程序化检查顺序）

> **源自**：《奇门遁甲预测学》幺学声·第六章·P96-98  
> *"我在多年实践当中摸索出一套定应期的方法，我把它程序化。"*

**总原则**：先分类→看大局伏吟反吟→五步检查→综合判断

### 第一步：分类定范围（先确定是哪种事）

| 预测类型 | 应期参考符号 | 应期精度 |
|----------|-------------|:--------:|
| 天气 | 值符、九星 | 日/时 |
| 地理风水 | 九宫地支 | 年/月 |
| 工作人事 | 八门、值使门 | 月/日 |
| 终身运气 | 年 | 年 |
| 一年内事 | 月 | 月 |
| 月内事 | 日 | 日 |
| 一日内事 | 时辰 | 时 |

### 第二步：大局定快慢（伏吟/反吟+内外盘）

| 条件 | 速度 | 时间跨度 |
|:----:|:----:|:--------:|
| 反吟局 | 快 | 内盘→日/时，外盘→月 |
| 伏吟局 | 慢 | 内盘→月，外盘→年 |
| 内盘(1/3/4/9阳遁) | 近快 | 数日~数月 |
| 外盘(2/6/7/8阳遁) | 远慢 | 数月~数年 |

### 第三步：五步检查（核心！程序化）

**按以下优先级顺序逐一检查**：

#### ① 空亡 → 冲空/填空为应期
- 用神宫逢空亡 → **冲空**（对冲地支）或**填空**（本支填实）时为应期
- 找到预测时间的地支在九宫中的位置，顺数到用神宫达到冲空或填空时止
- 例：用神在坤2宫(未申)逢空，戊子日预测→从子顺数到丑寅正好冲未申→丑寅时

#### ② 马星 → 马星动/冲马星为应期
- 用神宫不空但临马星 → 马星动时或冲马星时为应期
- 例：用神在坤2宫临马星→从预测日地支顺数到冲马星时为应期

#### ③ 墓库 → 冲墓/入墓为应期
- 用神宫不空也不临马星但入墓 → **冲墓**或**入墓**为应期
- 例：开门为用神落在艮8宫入墓→丑年月日时或冲丑的未年月日时为应期

#### ④ 刑冲合 → 以合为应期，以冲为应期
- 临刑、冲 → **合**为应期
- 临合 → **冲**为应期
- 例：甲午辛在离9宫击刑(午午自刑)→午与未合→未年月日时为应期

#### ⑤ 长生生旺 → 生逢生日，克逢克日
- 以上都不临时 → 依据用神的长生、生旺、墓绝定应期
- 生逢生日，克逢克日断

### 第四步：值使落点数

> *"值使门落震三宫发生的时间应定三年、三个月、三天或三十天、三个时辰。落坤二宫定二年、二个月、二十天或二天。"* —— 幺学声

| 值使落宫 | 可能的数字 |
|:--------:|:----------:|
| 坎1 | 1/10/100 |
| 坤2 | 2/20/200 |
| 震3 | 3/30/300 |
| 巽4 | 4/40/400 |
| 中5 | 5/50/500 |
| 乾6 | 6/60/600 |
| 兑7 | 7/70/700 |
| 艮8 | 8/80/800 |
| 离9 | 9/90/900 |

值使落宫数字 + 内外盘快慢 + 结合第三步的结论 → 交叉验证，时间吻合则判断准确

### 第五步：其他参考方法

- 值使门所临之天干为应期
- 用神宫所在宫的地支为应期
- 时干地盘天干为应期
- 结合外应综合断

> 原典强调：*"先定大局也就是大的范围，然后细分，逐步筛选，主次分清，灵活机动。"*

## 三、旺相休囚定应期（月令法）

**原理**：月令代表当时的旺衰状态，影响事情发生的速度

| 月令状态 | 应期特点 |
|----------|----------|
| 当令（旺相） | 事情来得快，近期发生 |
| 休令 | 事情来得慢，需等待 |
| 囚死 | 事情难发生，或已过 |

**文献出处**：
> 《图解奇门遁甲大全》第1部·第五章  
> *"月令旺衰是判断事情发生时间的重要依据。当令者事速成，失令者事迟滞。"*

## 十、《奇门遁甲预测学》应期五步法（最详）

> 《奇门遁甲预测学》幺学声·第五章·第二节·P97-98

### 10.1 五步优先级判断

**判断顺序（严格按优先级）**：

**第一优先：用神宫遇空亡**  
> 首先分类是时事、日事、月事、年事（远断年月，近断日时）。从预测时间的日支所在宫位，顺数地支，到用神所落宫构成冲时为应期。

**第二优先：用神宫逢马星**  
> 用神宫逢马星，无论遇生旺、墓绝、刑冲、庚格，均以马星动和冲马星为应期。

**第三优先：用神宫临墓库**  
> 用神宫临墓库之地，应以冲墓入墓为应期。临刑冲就以合为应期，临合就以冲为应期。

**第四优先：用神无上述情况**  
> 依据用神长生、生旺、墓绝定应期——生逢生日，克逢克日断。

**第五：值使门落宫数字**  
> 值使门落几宫，以宫数定年/月/日/时。内盘（1/3/4/9）近短，外盘（2/6/7/8）远长。

### 十一.3 应期推理三步曲

遇到应期问题时，严格按以下三步推理，**禁止跳步**：

```
第一步：为什么空/墓？
  → 找出旬空的地支/入墓的天干
  ↓
第二步：空/墓的具体内容？
  → 空：哪个地支空（子丑/寅卯/辰巳/午未/申酉/戌亥）
  → 墓：哪个天干入墓，入哪个宫
  ↓
第三步：什么事件冲填/冲墓？
  → 空：对冲地支（子午冲、丑未冲、寅申冲等）或填空（本支填实）
  → 墓：冲墓（如丑墓被未冲）或出墓
  → 再结合内外盘确定：是年/月/日还是时辰
```

> **实战警示**：必须写出完整三步曲，不能凭感觉跳步。案例中"乾宫逢空→明年3-4月"的跳步是错误的，正确链条是：乾宫空→戌亥空→对冲辰巳→辰巳对应农历3-4月→冲实为应期。
