# 奇门遁甲实战活案例库 v2

## Skill 概述

本库为滚动更新的真实预测案例记录，每次预测完成后追加条目。
与 `qimen-cases`（文献案例）不同，本库记录的是**实际操作案例**及其**应验结果**，
用于师傅 Agent 进行质量回溯和徒弟 Agent 的经验积累。

---

## 案例记录格式

每条案例按以下格式填写：

```
案例编号：[YYYYMMDD-序号]
事体分类：[10类问题中的哪类]
求测时间：[年月日时辰]
局数：[阴/阳遁 第X局]

排盘摘要：
- 值符/值使：
- 日干落宫：
- 时干落宫：
- 用神宫位：

徒弟断局：
[徒弟的原始输出，含用神旺衰、生克判断、格局、应期]

师傅修正：
[师傅的补充或纠错内容，如无修正填「无」]

最终结论：[事体判断 + 成败倾向 + 应期预测]

应验记录（事后填写）：
- 应验时间：
- 实际结果：
- 应验率评估：[完全应验 / 部分应验 / 未应验]

经验总结：
[本次预测中的收获或教训]
```
