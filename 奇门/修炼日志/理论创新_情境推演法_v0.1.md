# 情境推演法 v0.1（自创假设框架 · 待实战验证）

> **性质声明**：这不是书本内容，是我基于两个月学习（预测学95%+应用学100%+善天道100%+32份修炼日志实战规则）整合出的**个人方法论假设**。按真验证协议，本框架整体标 ⚠️未验证，须在后续实战中逐条检验，检验通过才可升级为"已验证规则"。
> **创新定位**：渐进式迭代，不推翻已有体系，而是在其上新增"情境转译层"，解决"解盘过于照书、不贴合具体情境"的核心痛点。
> **版本**：v0.1 | 2026-08-07 | 推演人：Loomy徒弟

---

## 一、要解决的问题（痛点诊断）

历史日志反复暴露同一个根本缺陷：**背书式解盘**。

| 症状 | 出处 |
|------|------|
| 看到符号→直接套书本断语→下结论 | 7/14推演反省 |
| 惊门=口舌是非，不看问的是什么事 | 7/14 |
| 辛+壬=讼狱不息，不问来人为何而来 | 7/14 |
| 吉门逢旺就断大吉，不看当事人高龄久病 | 应用学案例卷 |
| 找到一两个主象就停，漏次象 | 6/8反省 |

**根因**：书本给的是"符号→通用断语"的映射，但实战需要"符号×具体情境×能量状态→具体判断"的运算。中间缺了一个**情境转译层**。

---

## 二、框架总览：五层推演结构

```
第0层  定事定位（先问清楚，再碰盘面）
   ↓
第1层  能量状态前置（旺相休囚死/空墓刑迫，先算能量再谈象意）
   ↓
第2层  取用神（四分法分类 → 对应取神）
   ↓
第3层  情境转译（核心创新层：分离标注+象意翻译+多层推演）
   ↓
第4层  加权裁决（主导/辅助/局部信号加权 + 凶格计分 + 主客定策）
   ↓
输出：结论 + 应期 + 不确定性等级 + 📖/🧠来源标注
```

与七步流程的关系：**不是替代，是在第⑤步"析宫盘"内部展开细化**。七步是骨架，本框架是"析宫盘"这一步的显微镜。

## 三、第3层「情境转译」详解（本框架的核心创新）

### 3.1 分离标注法（最重要的单条创新）

对盘面每一个符号的判断，强制分两类标注：

| 标注 | 含义 | 可信度 |
|:----:|------|--------|
| 📖 | 直接来自书本断语 | 高（但需能量状态修正） |
| 🧠 | 我的情境转译/推演 | 待验证，须标明推理链 |

**规则**：
1. 每个符号先写📖层（书本怎么说），再写🧠层（在本情境下应怎么读）
2. 🧠层**必须给出推理链**（为什么这么转译），不能只有结论
3. 📖与🧠冲突时，以🧠为准但**保留📖原文**，供事后复盘对照
4. 交付给求测者时，🧠层的不确定性须如实告知

**为什么这是创新**：历史日志的误区是"把推演伪装成书证"（CB-01过早标✅的变体）。分离标注强制让"哪些是书说的、哪些是我推的"一目了然，既可防止盲信书本，也可防止把个人臆断包装成权威。这直接呼应"不可盲目相信"+"自我创新"两条要求。

### 3.2 情境转译三问

对每个关键符号，做🧠转译前强制回答三问：

| 问 | 内容 | 例（惊门） |
|:--:|------|-----------|
| ① 问事体 | 这个符号在当前所问之事里扮演什么角色？ | 惊门=学习之事门面，非惊恐之源 |
| ② 问正反面 | 该符号的正/负象意，哪个贴合本情境？ | 惊门正面=言语质疑，负面=惊恐口舌 |
| ③ 问能量 | 符号当前能量状态支持它发挥正面还是负面？ | 惊门迫宫=质疑耗能但必要 |

三问全过，才能下🧠转译结论。任何一问答不上，说明转译依据不足，须回到📖保守断或标"信息不足"。

### 3.3 多层推演链（至少推两层）

反对"符号→结论"一层跳跃。标准推演链：

```
符号象意 → 情境映射 → 行动含义 → （可选）再推一层
```

示例（今日自占局·癸加壬）：
- 层1（象意）：日时同宫，水叠水
- 层2（情境映射）：人与事同处，事在己手；同气相叠易在同类问题打转
- 层3（行动含义）：反省须产出可执行新规则，否则只是循环

历史教训LG-01（推理跳步）在本框架中升级为**强制项**：应期推理三步曲、象意推演至少两层，跳步即标记为"推理不完整"。

## 四、第1层「能量状态前置」详解

**核心原则：先算能量，再谈象意。** 这是纠正"只看星门吉凶不看旺衰"（历史偏误）的硬约束。

执行顺序（不可颠倒）：
1. 判旺相休囚死（落宫为主，月令为辅——6/14裁决）
2. 查四害：空亡/入墓/击刑/门迫（四避开，善天道）
3. 能量等级定调后，该符号的📖断语**按等级打折**：
   - 旺相：断语全额生效
   - 休囚：吉凶减半（吉不就/凶不烈）
   - 逢四害：吉格打折、凶格加重

**新增裁决规则（自创，待验证）**：
- **旺为库衰为墓**：同见墓库，月令有气作"库"（储能待用），月令无气作"墓"（困顿）。——此条源于善天道精华p5，但我把它升级为"能量状态前置"的强制判断步骤。
- **门迫吉凶反转检查**：凶门被迫，须先问该凶门在本情境是否为"必要之恶"（如惊门之于反省、伤门之于追讨），是则不单纯断凶。——此条为今日自占局推演所得，纯自创。

## 五、第2层「取用神」：四分法前置分类

沿用应用学四分法（静态/动态/九宫拟象/综合），但新增**前置强制分类**：

**规则**：取用神前，必须先明确本次预测属于四类中的哪一类。分类错误→用神全错→结论全错。这是应用学作者直言的"学不会奇门的根本症结"。

分类速判：
| 问法特征 | 类别 | 取神方向 |
|----------|------|----------|
| 问趋势/成败（婚姻/求财/考试） | 静态 | 日时干+事项用神 |
| 问方位/时机/趋避（出行/捕盗/来人） | 动态 | 主客+方位 |
| 问结构/部位（疾病/风水/孕产） | 九宫拟象 | 宫位比拟 |
| 复杂人事/综合运势 | 综合 | 多法并用 |

## 六、第4层「加权裁决」：整合实战规则

把12条实战规则收编为裁决阶段的强制检查清单：

| 检查项 | 规则 | 来源 |
|--------|------|------|
| 符号优先级 | 开门>值符>生门>星神（涉政策时开门置顶） | 6/15 |
| 凶格计分 | ≥3分断大凶，叠加相乘 | 6/8-6/15 |
| 信号加权 | 主导⭐⭐⭐定方向，局部不拉低全局 | 6/22 |
| 马星 | 中性变动，结合星门神定方向 | 6/15 |
| 逢空 | 方向待定，非空头 | 6/15 |
| 主客 | 五阳利客五阴利主+天地生克 | 应用学+善天道 |
| 前置检查 | 确认对象存在+查≥3条新闻 | 6/19 |

**裁决输出格式（强制）**：
```
结论：…
主导信号：…（⭐级）
应期：…（三步曲完整）
不确定性等级：复盘型/预测型 + 高/中/低
来源标注：📖x条 🧠x条
```

## 八、待验证清单（本框架的检验计划）

本框架整体⚠️未验证。后续实战须逐条检验：

| 待验证项 | 检验方式 | 通过标准 |
|----------|----------|----------|
| 分离标注法 | 每次解盘强制标注，复盘对照🧠准确率 | ≥3次独立验证 |
| 情境转译三问 | 对同一盘面，三问转译 vs 直接背书，对比贴合度 | 求测者反馈+事后验证 |
| 能量打折规则 | 休囚符号断语减半，验证吉凶幅度 | ≥3次 |
| 旺库衰墓裁决 | 墓库同见时按此裁决，验证应事方向 | ≥3次 |
| 门迫吉凶反转 | 凶门"必要之恶"判断，验证是否应凶 | ≥3次 |
| 四分法前置分类 | 分类正确率 vs 结论正确率相关性 | 累计统计 |

**升级规则**：任何一条通过≥3次独立真验证（非复盘型），才从"⚠️假设"升级为"已验证规则"，并回写知识库。未通过则降级或废弃。
