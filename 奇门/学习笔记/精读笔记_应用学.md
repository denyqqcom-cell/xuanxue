## 二、独有内容重点摘录（《预测学》没有的）

### 2.1 预测方法四分法（第七章 p217-222）⭐核心方法论

本书最重要的独有贡献——把奇门预测按性质分为四类，解决了"什么事件用什么方法"的根本问题：

| 方法 | 定义 | 适用场景 | 关键特征 |
|------|------|----------|----------|
| **静态类** | 模拟事物从某时间点到另一时间点的线性变化趋势 | 贸易/考学/官司/婚姻/失物/怪异 | 重日干时干用神旺衰生克，方位空间非决定因素 |
| **动态类** | 不同时间或空间背景下的多项时空选择预测 | 出行趋避/捕盗/避难/迁移/来人善恶/谈判位置 | ①同时间不同方位比较 ②不同时间不同方位比较 ③**主客方针策略** |
| **九宫拟象** | 以九宫比拟人体/事物结构/发展阶段 | 疾病/家居风水/孕产/射覆 | 类似六爻爻象比拟法 |
| **综合预测** | 上述三类的综合运用，随机应变 | 复杂人事/全方位运势 | "唯心所变，唯机是从，唯我所用"；需精通外应十应 |

> ⚠️ 作者直言："以往许多人学不会奇门遁甲……根本症结就在于没搞清楚这四种方法的区分。对各种事件不分类别、事态不求动静、不分主次堆积使用、张冠李戴瞎蒙乱碰。"

### 2.2 主客关系体系（第九章 p219-220）⭐实战核心

动态类预测的核心工具，《预测学》未系统论述：

- **主者** = 消极被动/后动/柔/静 → 地盘星仪代表
- **客者** = 积极主动/先动/刚/健 → 天盘星仪代表
- **判断规则**：
  - 主克客 → 利主不利客 → 占据有利地形、静以待敌
  - 客克主 → 利客不利主 → 主动进击、一鼓作气
  - 客生主 → 为主；主生客 → 为客
  - 主客比和 → 两相皆宜
- **补充原则**：九星旺衰程度，旺者胜衰者负，旺能克衰

### 2.3 来意占断方法论（第六章第七节 p196-205）

系统化来意推断流程：
1. **社会心理学先行定格**：中年男→事业/财运；中年女→婚姻/家庭/疾病；少年→升学/恋爱；老年→健康/子女
2. **日时干落宫定性**：乘开门=工作事业；乘生门=财运经商；乘死门=刑丧破败
3. **来人方位/电话方位**结合九宫信息
4. **日时干加临地盘奇仪细化**：加庚=男人/疾病/阻碍；加丁=少女/文书/手机；加戊=长者/财物；加乙=妻子/中介；加辛=罪犯/狱卒
5. **相学气色观人辅助**（p206-216完整附录）：十二宫/十三部位/七色所主/年龄差异/具体观测法

> 作者态度："来意占断是诸多易学预测方法中的难点……没有任何一种方法可以大包大揽。"反对故弄玄虚、赌输赢。

### 2.4 九宫拟象预测（第十章 p281-300）

以九宫比拟事物的特殊方法：
- **家居风水**：九宫对应房屋各区域，结合星门神格局判断吉凶；案例39详述客厅移位的奇门+六爻双重验证
- **疾病预测**：九宫对应人体部位（坎=肾/耳、离=心/目、震=肝/足等），结合天芮病星、十天干脏腑配属
- **射覆孕产**：以九宫拟象猜物、断胎儿性别/产期

### 2.5 流派介绍（第十二章 p399-415）⭐拓展知识

#### 年家奇门
- 三元甲子说：每60年一元，180年一大运（上中下三元）
- 演局：上元一宫起甲子、中元四宫、下元七宫；阴遁布局；值符随年干、值使随年支
- 用途：国家大事、年内吉凶

#### 月家奇门
- 以12个月为一元；甲己年干为符头
- 年支子午卯酉→坎一起甲子；寅申巳亥→巽四；辰戌丑未→兑七
- 俱用阴遁；值符随月干、值使随月支
- 用途：进京赶考/外出仕宦/经商出行/玄空风水择吉

#### 日家奇门（两套方法）
- **方法一**：冬至后阳遁分三元（各约60天）；上元一宫起甲子、中元七宫、下元四宫；阴遁反之
- **方法二**（《遁甲演义》《金函玉镜》）：九星吉凶次序（太乙/摄提/轩辕/招摇/天符/青龙/咸池/太阴/天乙）；一日一星循环；八门三日一移；另含十二黑黄道/喜神/天乙贵人/截路空亡

#### 飞宫法
- 与排宫法（活盘/转盘）的区别：九星/奇仪/九门依次入中宫飞布，而非转盘旋转
- 增设中门（无中宫寄坤之说）
- 八神名称不同：值符/蛇/太阴/六合/勾陈/太常/朱雀/九地/九天
- 作者评价："二者各有所长，不能遽下结论。'人于心上起经论'。"

### 2.6 相学气色观人法（第六章附 p206-216）

完整的面部气色观测体系，作为来意占断的辅助工具：
- 十二宫相法（命宫/财帛/兄弟/田宅/子女/奴仆/妻妾/疾厄/迁移/官禄/福德/父母）
- 十三部位（天中/天庭/司空/中正/山根/年上/寿上/准头/人中/承浆/地阁等）
- 七色所主：紫=大吉、红=喜庆、黄=升迁、赤=讼狱血光、白=忧愁孝服、青=惊忧愤怒、黑=病灾破财
- 各部位具体观测法（额顶/福德/日月角/印堂/迁移/天仓/鱼尾/奸门/泪堂/山根/颧骨/鼻/法令/食禄/口唇/承浆/地阁）

### 2.7 综合案例详解（第十一章 p301-398）

45个完整案例，远超《预测学》的案例数量和深度。涵盖：

- 人事预测（留学签证p325、工作调动p323、选举p317）

- 日常杂项（钥匙丢失p338、儿子玩耍方位p339、自行车被盗p336-337）

## 三、与《预测学》的差异点

| 维度 | 《预测学》幺学声 | 《应用学》王云鹏 | 分歧/互补 |
|------|------------------|------------------|-----------|
| 预测分类 | 按事项分（疾病/婚姻/求财…） | 按方法分（静态/动态/拟象/综合） | **互补**：应用学的四分法是更上层的方法论框架 |
| 主客关系 | 简略提及 | 系统论述（p219-220） | **应用学独有** |
| 来意占断 | 未专论 | 完整方法论+相学辅助 | **应用学独有** |
| 流派介绍 | 仅时家奇门 | 年家/月家/日家/飞宫法 | **应用学独有** |
| 案例数量 | ~20个 | 45个 | 应用学案例更丰富、更贴近现代商业社会 |
| 拆补法 | P66-68内部矛盾 | p112-114明确推荐拆补法，案例一律采用 | **一致**：均倾向拆补法 |
| 十干克应 | P76-79完整40组 | p197-199引古籍捷法+出门一里应 | **互补**：应用学补充了动态出行克应 |
| 相学气色 | 无 | p206-216完整附录 | **应用学独有** |
| 运筹/功法 | 无 | 前言提及但未展开 | 遗憾：仅有标题承诺 |

### 主要分歧
- **无明显理论冲突**。两书在基础理论（干支/九宫/排盘/格局）上高度一致
- 应用学的"预测方法四分法"是对预测学的**上位整合**，不是替代
- 应用学案例年代（1996-1999）比预测学（2001-2004）更早，但商业场景更丰富

## 四、最有价值的新知识点 TOP 5

1. **预测方法四分法**（p217-222）：解决"什么事件用什么方法"的根本问题，是学习奇门的"钥匙"
2. **主客关系体系**（p219-220）：动态预测的核心决策工具，地盘=主/天盘=客，五种生克关系定策略
3. **来意占断五步法**（p196-205）：社会心理学定格→日时干定性→方位辅助→奇仪细化→气色印证
4. **日家奇门第二套方法**（p407-412）：《遁甲演义》《金函玉镜》体系，九星一日一移+八门三日一移+十二黑黄道
5. **飞宫法完整规则**（p413-415）：与排宫法的本质区别（飞布vs转盘）、增设中门、八神名称差异
