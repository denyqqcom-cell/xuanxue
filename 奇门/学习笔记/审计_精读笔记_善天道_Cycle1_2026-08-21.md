## 1. 第一处旧误区：把 TEXT 提取叫成“精读”

旧笔记开头明写内容提取自 `_txt/善天道精华.txt、善天道讲义.txt、善天道高级班.txt`，却命名为“三本讲义精读笔记”。这会把“文本抽取已浏览”长期记忆成“原页、图表、版面、错字都核验过”。

现在保留旧笔记作为 prior model / 搜索索引，不再把名称当 Reading 证明。

分类：`COVERAGE_SEMANTICS_ERROR`。

## 2. 第二处旧误区：71 页讲义的结构地图严重塌缩

旧笔记对 71 页本的结构地图基本停在 p15，遗漏：

## 3. 第三处旧误区：把八神体系过度简化成“不同书各用一套”

旧笔记曾把“讲义=飞宫体系、精华=排宫体系”作为主要区分。canonical 71 页本视觉复核直接否定这种简单映射：

- p27 明写本书用排宫法；
- p31 与 p55 对勾陈/朱雀、白虎/玄武关系给出互相冲突的映射线索；
- p31 自身还出现称“八神”但阳遁列项不足的不完整文本；
- p19-p20 又记录小值符运转有不同说法。

所以问题不是“选对一个 enum”就结束，而是 source 本身有内部版本/编辑/谱系问题。

当前状态：`SOURCE_INTERNAL_CONFLICT / DEITY_LINEAGE_UNRESOLVED`。

工程上的 deity freeze 继续有用，但不能冒充历史真相。

## 4. 第四处旧误区：把“书中有规则”升级成“项目核心资产”

旧笔记大量使用：`最实用 / 核心资产 / 标准化流程 / 更果断 / 更完整 / 可合并 / 更系统化`。

这些不是 Source Fidelity，而是旧项目的 operational promotion。没有 matched prospective comparison，就不能因为写得详细、步骤多、句子具体而获得更高权重。

现在统一改写为：

`SOURCE HAS A STRUCTURE -> CANDIDATE HYPOTHESIS`，

而不是：

`SOURCE IS DETAILED -> PROJECT SHOULD ADOPT IT`。

分类：`UNVERIFIED_OPERATIONAL_PROMOTION`。

## 5. 第五处旧误区：高风险断语被当成“最有价值知识”

旧笔记把疾病预测、死亡应期等列入核心资产。本书原页确实有大量疾病、死亡、癌症、刑事、犯罪、诉讼等具体断语，但“作者写得具体”不构成现实可靠性。

统一隔离：`HIGH_RISK_SOURCE_CLAIM / RESEARCH_ONLY / NOT_EMPIRICAL_SUPPORT`。

这些内容最多用于研究“它怎样选择角色/结构/应期”，不能直接用于现实医疗、法律、犯罪事实判断。

## 6. 第六处旧误区：默认把整本书看成一个方法层

完整视觉复核后，method-layer shift 比先前预估更明显：

- p46 与 p49 重复“第五章”；
- p49-p50 才加入暗藏飞干；

这是一份多层教学汇编的强信号。不能把所有段落自动压成同一算法链或同一时代层。

候选拆层：

`STANDARD_PLATE / HIDDEN_FLYING_STEM_AUX / SYMBOLIC_LEXICON / APPLIED_ROLE_MAP / HIGH_RISK_SOURCE_CLAIMS`。

## 7. 第七处新发现：原载体本身有大量 Source Fidelity 风险

视觉复核发现 text layer 很难揭示的错误/损坏候选：

- p27 明显坏词及八门表异常；
- p29 天星/天英不一致；
- p35 三奇升殿命名冲突；

- p53-p55 地支、五行、节气材料多处异常；
- p55 日期/节气示例内部不相容。

过去的错误不是“没有背对”，而是默认 source 是干净的。以后必须允许：

`SOURCE ITSELF MAY BE WRONG OR CORRUPTED`。

模型不能依据常识替作者偷偷改字，再把修后的内容冒充原文证据。

## 8. 第八处新发现：从“死模板”走向“无限象意”同样会过拟合

这是本轮最重要的自我修正。

过去我们主要批判：

`单一符号 -> 固定断语`。

本书 p59 以后则强调把奇门当庞大意象语言，靠记忆与想象翻译组合。这个方向比死背条文更有情境感，但如果不受约束，会变成另一种问题：一个符号可以对应人物、器官、机构、物件、疾病、行为、方位等大量语义，事后总有机会挑出“看起来很准”的那个。

所以：

`灵活 != 可验证`，

`有想象力 != 有解释力`。

当前方法论 refinement：

`Semantic Expansion Penalty / 语义自由度预算`。

凡能在结果后改选的 Role Map、象意词、格局条件、应期、deity alias，都必须结果前冻结或进入显式 A/B。宽词典必须面对更强 negative control，而不是获得更高自由裁量权。

这才是真正从“背书式解盘”继续往前一步，而不是从一个极端跳去另一个极端。

## 9. 第九处新发现：同书重复不能当独立支持

后半本多处重复前文占事/规则。以前知识库容易因为“一条规则出现多次”产生心理加权。

现在明确：

`INTRA_SOURCE_REPETITION != INDEPENDENT_SUPPORT`。

同一载体重复编排只算一次来源，不增加独立性，也不增加经验支持。

## 10. 旧笔记仍然保留什么价值

`KEEP`：

- 检查哪些内容过去最容易让项目兴奋；

`REVISE`：

- “更系统化=更可靠”的评价；
- 对 K2 COMPLETE 的心理语义。

`DELETE`：

- “最实用/核心资产”自动取得运行优先级；
- 同书重复自动增加置信度；
- 无限象意可在结果后自由挑选；
- 高风险断语因具体而被视为高价值 operational knowledge。

`NO-OP`：

- 暂不新增 deity enum；
- 暂不升级理论版本；
- 暂不因为视觉发现支持某套传统就改 production。

## 11. 本轮后的反向阅读纪律

1. 先找 source corruption / internal conflict，再摘“规则”；
2. 先找会让当前模型失败的条件，再找支持条件；
3. 同书重复去重；
4. 任何宽象意必须记录可选语义数量/范围，防止结果后挑词；
5. 来源定义、结构可复现、现实有效性分别记账；
6. 当 `NO-OP / DELETE` 是最合理结果时，不为了显示成长强行新增理论。

## 12. 当前结论

这轮真正的增量不是“善天道又提供了更多象意”，而是把两类相反的错误同时暴露出来：

`死扣条文` 与 `无限联想`。

自己的理论如果要长出来，核心不该是比古书拥有更多解释，而应该是**更少的结果后自由度、更清楚的来源边界、更严格的反证与负对照**。

当前仍维持 v0.3-alpha，不宣称预测准确率提升。
