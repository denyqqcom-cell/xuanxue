### 2.1 上中下元符头规则（p4）
```
上元第一天日支：子午卯酉 → 符头：甲子、甲午、己卯、己酉
中元第一天日支：寅申巳亥 → 符头：甲寅、甲申、己巳、己亥
下元第一天日支：辰戌丑未 → 符头：甲辰、甲戌、己丑、己未

超神 = 上元符头在前，节气在后
接气 = 节气在前，上元符头在后
置闰 = 上元符头超过节气九天
★ 推荐方法：拆补法（不置闰）
```

## 三、高级班断局方法论重点 ⭐核心资产

### 3.1 断局两原则（p2）
- **急则从神**：紧迫事件→向值符落宫方向行动
- **缓则从门**：有时间冷静分析→以八门为核心思考（"天时不如地利，地利不如人和"）

### 3.2 四个避开（p2-3）
1. 避开**五不遇时**（时干克日干，阳克阳/阴克阴）
2. 避开**时干入墓**（事情纠结、情况不明）
3. 避开**六仪击刑**（大凶兆头）
4. 避开**庚与其他三奇六仪的组合**（庚克甲木统帅）

> 同时尽量选择三奇+三吉门（开/休/生）结合的格局

### 3.3 参数能量状态（p5-6）
- 八门/九星：按五行旺相休囚死五种状态
- 天干：12状态（长生→沐浴→冠带→临官→帝旺→衰→病→死→墓→绝→胎→养）
- **断局时必须把涉及参数的能量标注出来**

### 3.4 主客动静判断（p6）
| 维度 | 利客利动 | 利主利静 |
|------|----------|----------|
| 十天干 | 前5干（甲乙丙丁戊） | 后5干（己庚辛壬癸） |
| 伏吟/反吟 | 反吟局 | 伏吟局 |
| 天地能量 | 地盘生天盘 | 天盘生地盘 |

### 3.5 基本盘面分析五条（p7-8）⭐标准化流程
1. 标年干/月干(含月支)/日干/时干 + **日空时空四个地支**
2. 标六仪击刑、入墓
3. 定马星位置（冲动可打掉墓和空）
4. 观察伏吟/反吟 + **天显时格**（表面伏吟但经波折后终吉）
5. 确定当事人参数：**倾向用年命而非日干**（信息量更强）

### 3.6 应期确定三条（p9-10）
1. **逢空逢墓**：被冲空/填空之时为应期
2. **值使落宫数字**：结合内外盘取数（内盘取小数=快/近/少；外盘取大数=慢/远/多）
3. **马星冲动**：冲动对宫或本宫时为应期

### 3.7 内外盘定义（p9）
- 阳局内盘：8、3、4、1（左盘）；外盘：9、2、7、6（右盘）
- 阴局内盘：9、2、7、6（右盘）；外盘：8、3、4、1（左盘）
- 内盘=小数/快/近；外盘=大数/慢/远

### 3.8 疾病预测六步骤（p13-14）
1. 断病部位：天芮落宫天干（旺者为病位）+ 落宫五行
2. 看患者年命落宫（抗病能力）
3. 看时干辅助信息
4. 确定治疗方向：天心(西医)/乙奇(中医)能否克天芮
5. 重病死亡应期：**冲动病宫**或**填实病宫**之时 + 值使门数字参考
6. 十干宫位对应疾病图

### 3.9 婚姻预测五参数体系（p45）
- 乙=妻子/女友 | 庚=丈夫/男友 | 六合=婚姻
- 丙=男小三 | 丁=女小三
- 分析框架：乙庚关系→乙庚与六合关系→丙丁介入情况→离婚条件(财产/子女)

## 四、与幺学声《预测学》体系的差异

| 维度 | 幺学声《预测学》 | 善天道体系 | 评价 |
|------|------------------|-----------|------|
| 起局方法 | 拆补法/置闰法并列，内部矛盾 | **明确推荐拆补法**（精华p4） | 善天道更果断 |
| 断局入口 | 七步流程 | 两原则+四避开+五条基本面 | **互补**：善天道更实操化 |
| 当事人参数 | 日干为主 | **倾向年命**（高级班p8） | 分歧：需实战验证 |
| 主客关系 | 简略 | 三维度系统判断（天干/伏反吟/天地能量） | 善天道更完整 |
| 应期方法 | 五步程序化检查法 | 三条（空墓/值使数字/马星） | **互补**：可合并使用 |
| 用神体系 | 按事项分类叙述 | **速查表格式**（精华p26-28） | 善天道更便于实战 |
| 疾病预测 | 九宫人体+案例 | 六步骤+死亡应期双标准 | 善天道更系统化 |
| 生育预测 | 简略 | 终身局+环境调理方案 | 善天道独有 |
| 道德规范 | 未专论 | 实事求是/保护隐私/善良正义 | 善天道独有 |
| 天显时格 | 完整六甲旬首定义 | "表面伏吟但经波折后终吉" | **一致** |

### 主要分歧点
1. **当事人参数**：幺学声用日干，善天道倾向年命——需在实战中对比验证
2. **应期精度**：善天道强调值使落宫数字+内外盘取数，比幺学声的五步法更简洁但可能精度不同
3. **八神名称**：善天道讲义用"真符/勾陈/太常/朱雀"（飞宫法八神名），精华本用"值符/白虎/玄武/太阴"（排宫法八神名）——两套体系混用需注意
