# 奇门遁甲师傅-徒弟解盘工作流规范

> **版本**: v3.0 | **更新日期**: 2026-03-27  
> **核心定位**: 用户 + 徒弟（Claw）+ 师傅（WorkBuddy）三方操作流程

---

## 总览：三方角色与职责

```
┌─────────────────────────────────────────────────────────────────┐
│                         用户（人类）                              │
│  职责：提供排盘数据 + 事体描述，阅读最终结论，可追问               │
│  操作：说一句话 → 等待 → 看报告 → 可追问                         │
│  读取文件：最终结论_*.md（可选读核查报告）                        │
└──────────────────────────┬──────────────────────────────────────┘
                           │ 排盘数据 + 事体描述
                           ▼
┌─────────────────────────────────────────────────────────────────┐
│              徒弟 Claw（WorkBuddy 加载 qimen-* 模式）             │
│  职责：按八步法执行解盘分析，输出分析报告                         │
│  知识库：qclaw/ 下 12 个 qimen-* 技能（善天道实战派）            │
│  指令文件：qclaw/_AGENT_INSTRUCTIONS.md                         │
│  读取：用户输入 → _META.md → qimen-* SKILL.md                   │
│  写出：claw_问题分类 ~ claw_格局详解（8个）+ claw_完整断局       │
└──────────────────────────┬──────────────────────────────────────┘
                           │ claw_完整断局_YYYYMMDD.md（交接文件）
                           ▼
┌─────────────────────────────────────────────────────────────────┐
│              师傅 WorkBuddy（加载 qmdj-* 核查模式）               │
│  职责：用古籍文献核查徒弟分析，修正错误，补充遗漏                  │
│  知识库：.workbuddy/skills/ 下 7 个 qmdj-* 技能（金函玉镜古籍）  │
│  指令文件：qmdj-review/_AGENT_INSTRUCTIONS.md                   │
│  读取：claw_完整断局_*.md + _META.md（仅这两个）                 │
│  写出：workbuddy_核查报告_*.md + 最终结论_*.md                  │
└──────────────────────────┬──────────────────────────────────────┘
                           │ 最终结论 + 核查报告
                           ▼
                        用户阅读报告
```

|------|----------|------|
| 师傅有明确古籍依据 | 以师傅为准 | 「依古籍修正」+ 出处 |
| 师傅无古籍依据 | 两种结论并列 | 「存疑」 |
| 两套体系均无覆盖 | 建议参考其他文献 | 「待考」 |
| 徒弟有创新见解 | 保留但标注未验证 | 「新见」 |

### 绝对红线（三方通用）

| 红线 | 适用对象 | 说明 |
|------|---------|------|
| 脱离事体论格局 | 徒弟+师傅 | 所有分析必须紧扣用户事体 |
| 混用知识库 | 徒弟+师傅 | 徒弟只用 qimen-*，师傅只用 qmdj-* |
| 跳步 | 徒弟+师傅 | 徒弟八步必全，师傅六项必查 |
| 无据推翻 | 师傅 | 修正必须有古籍出处 |
| 改元数据 | 徒弟+师傅 | `_META.md` 创建后不可修改 |
