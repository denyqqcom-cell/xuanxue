# qimen-core

奇门遁甲的纯 Kotlin/JVM 核心模块。当前阶段严格按 `handoff/qimen/` 的工程交接实现，**不是完整九宫排盘器**。

当前允许实现：

- 公历日柱双锚点校验
- 13 时辰与晚子滚日策略
- 五鼠遁时柱
- 旬首、遁仪、旬空
- 精确节气时刻（复用项目现有 `lunar-java`，不用“立春 2.4”之类近似日期）
- 拆补日数分段的三元/局数表
- 五不遇时 generator 与善天道印刷十条的可选比较模式
- 六仪击刑静态映射

当前明确禁止：

- 伪造地盘、天盘、人盘、神盘
- 置闰、拆补符头、茅山、飞宫
- 真太阳时
- 十干克应/判断辞典直接进入 core

`QimenEngine.cast()` 对未实现流派返回 `UnsupportedSchool`，不会用默认盘冒充。

测试种子复制自 `handoff/qimen/05_FIXTURES.jsonl`；没有新增任何现代书籍长段文字、扫描页或 540 局图表。
