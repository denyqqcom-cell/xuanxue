## 3. Work lineage：不能把三册合成一本

完整内容不支持把 0027/0028/0029 标成 SAME_WORK_VARIANT 或 WORK_PART：

- 0028 是 71 页基础讲义，重心在定局、排盘、基础格局与分类占事入口；
- 0029 是 294 页高级班讲义，扩展主客、旺衰、取用、应期以及大量分类案例；
- 0027 是 32 页“精华培训教材”，呈高度压缩的速查/汇编形态。

因此原有三个 `work_id` 保留，不为“看起来同源”而错误坍缩作品边界。

## 4. Course provenance：三本也不能当三张独立票

虽然是不同作品，但内容显示明显同一教学体系：

- 0027 p4 将“不置闰—拆补法”压缩为推荐方法；0028 p17-p18 对拆补/置闰作展开论述；
- 0027 p26 的大选取用为候选人年命、开门、时干等；0029 p284 以同一角色结构进入选举案例；
- 0027 p27 的诉讼角色包含值符、开门、景门、六合、惊门等；0029 p212 的诉讼取用呈同一框架并作扩展。

因此建立 `COURSE-QM-SHANTIADAO-001`：

- 0028 = FOUNDATION；
- 0029 = ADVANCED_EXTENSION；
- 0027 = SYNOPSIS_COMPENDIUM。

结论：

`distinct works + shared teaching provenance`

同家族内容相互重复时，最多取得一个 provenance-family credit，不得因三个 PDF 一致而计三票。

## 7. QM0029 p287-p294 的末尾结论

最后八页继续的是选举案例：

- p287-p290：2008 美国总统选举案例；
- p291-p294：2016 台湾地区领导人选举案例；
- 之前 p284 起已明确候选人取年命、职位取开门、选民取时干的角色映射。

末尾案例共同特征：

1. 作者在盘后逐层加入空、墓、马星、旺衰、门星关系与候选人互生克；
2. 存在“入墓但被马冲”“逢空但因状态强而减弱空的解释”等修正路径；
3. 案例随后给出实际结果反馈。

这些页可以证明：

> 该高级班确实用这套方法解释这些已知案例。

不能证明：

> 这套规则已经获得独立、前瞻、冻结条件下的预测有效性。

因此这些 retrospective case 目前 `empirical_credit = NONE`。若未来要测试“马冲解墓”“旺可减空”等修正规则，必须在结果揭晓前冻结触发条件、优先级与失败条件，防止事后自由度。

## 9. 本轮方法论修正

本轮暴露了旧模型的一个缺口：

`work independence` 与 `teaching provenance independence` 不是一回事。

如果只用 `K2_SOURCE_LINEAGE`，0027/0028/0029 会因不同 work_id 被误当成三份独立支持，从而产生 lineage vote inflation。

新增 course-provenance 层后，模型改为：

`SOURCE -> WORK IDENTITY -> COURSE PROVENANCE -> EVIDENCE -> RE-AUDIT -> CLAIM REVIEW`

这比直接修改 50 条 Evidence 更可审计：来源说过什么被保留，而项目后来学会的“降权、冻结、不可独立投票”也有独立记录。
