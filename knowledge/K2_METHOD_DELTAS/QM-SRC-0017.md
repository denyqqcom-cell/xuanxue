## Delta 1 — Source Position Separation becomes a permanent reading discipline

Confirmed correction:

`SOURCE_CONTAINS(X) != AUTHOR_ENDORSES(X)`.

The carrier preserves large quantities of inherited deterministic material while its final critical volume explicitly attacks some inherited origin myths, omen-like `动应` and talismanic/superstitious layers.

Therefore every future source review should conceptually separate:

- `TRADITION_RECORDED`;
- `AUTHOR_EXPLANATION`;
- `AUTHOR_CRITIQUE`;
- `AUTHOR_OPERATIONAL_COMMITMENT`.

This remains a reading discipline rather than a new mandatory schema field unless existing Evidence/Distillate semantics prove unable to preserve the distinction.

Compression rule:

If current fields can already represent the distinction, **do not add another registry column merely because the concept has a name**.

## Delta 2 — Contextual reasoning loses any presumed superiority

The book's large fixed lookup corpora create a credible simpler rival:

`SOURCE_FIXED_LOOKUP`

versus

`CONTEXT_FROZEN_RELATIONAL`.

The project must stop treating “more contextual / more relational” as a synonym for “more capable”.

New requirement:

Context machinery earns retention only if it improves at least one of:

- reproducibility;
- discrimination;
- calibration;
- appropriate abstention;
- robustness across matched contexts;

without an unjustified complexity cost.

If the simpler source-bound model performs equally or better, context keys / relation layers should be `NARROW / MERGE / DELETE`.

This is a direct correction to the old anti-template instinct that could otherwise become anti-simplicity bias.

---

## Delta 3 — Shared terminology must not force ontology unification

Full review confirms the book contains several time-family methods whose object sets and algorithms are not merely bureau-number variants of one universal plate.

In particular, day-family material introduces a different star ontology while reusing gate and calendrical vocabulary.

Therefore:

`shared terminology != shared ontology`

and:

`same tradition label != same executable method family`.

Project consequence:

- `time_family` remains a first-class freeze variable;
- runtime models may need separate object schemas, not just flags inside one engine;
- cross-family comparison must specify which objects are genuinely homologous before sharing interpretation rules.

This is a **split-before-merge** discipline, not a claim that all families deserve operational support.

---

## Delta 4 — State classification and effect-size remain separate

The source uses classifications, fixed labels and conditional prescriptions for stars/gates, but full review does not provide evidence sufficient to justify project-wide numeric effect-size weights.

Therefore retain:

`STATE_CLASSIFICATION != EFFECT_SIZE`.

Consequences:

- no resurrection of old “旺相全额 / 休囚减半” style weights;
- no universal star-state or door-state multiplier from this book;
- source-specific state systems may be encoded only when the algorithm is clear enough to reproduce;
- predictive effect still requires prospective comparison.

## Delta 6 — Final critique does not create an “everything else validated” remainder

The final critical volume shows the author is not blindly accepting all inherited material.

But a dangerous inverse inference would be:

`author criticizes A/B/C -> remaining D/E/F are validated`.

That is invalid.

Correct update:

`critical stance -> stronger source-position awareness`

not:

`critical stance -> empirical credibility transfer`.

This reinforces the project's Source / Truth / Applicability / Empirical separation.

## Delta 7 — Original theory should search for irreducible structure, not a grand synthesis

Full-book review makes a “great unified Qimen” approach look increasingly risky because different families reuse names while changing the underlying object system.

The more defensible research direction is to search for the **smallest cross-family structural core** that survives explicit ontology separation.

Current candidate abstraction:

`OBJECT -> ROLE -> STATE -> RELATION -> DISCRIMINATING OUTCOME`

with external controls:

`SOURCE POSITION -> METHOD FAMILY -> FALSIFICATION -> COMPRESSION`.

This is not promoted as v0.4. It is a compression target to be attacked by future sources and prospective cases.

## Final theory action

### KEEP

- `FRAME -> FREEZE -> RELATE -> DISCRIMINATE -> FALSIFY -> COMPRESS`;
- Object Type Safety;
- model/selection/stopping Degrees-of-Freedom control;
- source/implementation/empirical credit separation;
- explicit unresolved/fail-closed behavior.

### NARROW

- “contextual reasoning is better” becomes only a testable hypothesis;
- context must reduce legal interpretation space, not merely enrich narrative;
- cross-family shared labels cannot imply a shared ontology.

### TEST

- `SOURCE_FIXED_LOOKUP` vs `CONTEXT_FROZEN_RELATIONAL`;
- source-defined state classification vs no-state ablation;
- selected fixed-bureau structures vs wrong/permuted controls;
- cross-family object-homology before any shared runtime rule.

### NO-OP

- no v0.4;
- no universal deity mapping;
- no universal state multiplier;
- no global adoption of this book's fixed lookup tables;
- no empirical-support increase from full reading alone.

### DELETE / MERGE candidates

Any context field, relation layer or symbolic expansion that cannot outperform the simpler frozen rival on prospective data should be removed even if it sounds theoretically elegant.

---

## Failure conditions for this delta

This method delta should itself be revised if future evidence shows:

1. a simpler source-fixed model consistently outperforms the current relational method;
2. supposedly distinct time-family ontologies are shown by earlier source lineage to be mechanically isomorphic after explicit mapping;
3. the source-position distinction produces no practical reduction in false promotion and only adds paperwork;
4. no prospective benefit appears from the retained six-step theory skeleton;
5. model compression repeatedly removes the contextual machinery without loss of discrimination.

The delta has no immunity because it is “our own method”.
