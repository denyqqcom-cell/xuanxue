## 2. Competing lineage hypotheses

The current evidence now permits at least five materially different source models.

### H1 — ALIAS_WITH_CONTEXT

`白虎 ≈ 勾陈`, `玄武 ≈ 朱雀`, with naming selected by context.

Problem: p31 ordering/substitution language and p55 / QM-SRC-0021 hidden-layer language are not identical claims; QM-SRC-0022 also shows distinct simultaneous `朱 / 白` positions that a simple two-pair alias model does not explain.

### H2 — LAYERED_HIDDEN_DEITY

`白虎` and `玄武` are visible deity positions while `勾陈` and `朱雀` are hidden/subordinate layers.

Support is stronger because both Shantiandao p55 and visually reviewed QM-SRC-0021 p54/p57 use a layered formulation.

Problem: this still does not automatically explain Liang's direct `勾陈/朱雀` eight-deity list, Shantiandao p31's yin/yang substitution wording, or QM-SRC-0022's simultaneous `朱 / 白` positions.

### H3 — YIN_YANG_SUBSTITUTION

The name pair changes with yin/yang escape.

Support: the explicit Shantiandao p31 statement.

Problem: the same p31 sequence is visibly incomplete/corrupted, while p55 and QM-SRC-0021 give a different relationship description; QM-SRC-0022's p22 sequence also contains `朱` and `白` together inside one movement description.

### H4 — EDITORIAL_SYNTHESIS / MULTIPLE_METHOD_LAYERS

The 71-page carrier combines teaching material from more than one naming/movement lineage, so no single mapping should be inferred from the whole book.

Support: broader Cycle-1 evidence of duplicated chapters, method-layer shifts, source corruption and mixed symbolic material.

The new earlier witness makes this broader methodological caution more plausible across the corpus: later modern syntheses may be flattening multiple older naming systems rather than preserving one universal enum.

Problem: historical transmission paths still require genuine bibliographic/variant research; this hypothesis cannot be promoted merely because the modern sources disagree.

### H5 — ZHU_BAI_DUAL_POSITION / SOURCE-SPECIFIC DEITY SET

At least one earlier Qimen witness uses an eight-position deity sequence in which `朱` and `白` are separate simultaneous positions, alongside `直符 / 蛇 / 陰 / 六合 / 九地 / 九天`.

Support: targeted original-page QM-SRC-0022 p22 + p37.

This is currently the strongest direct evidence that a universal modern two-pair normalization is unsafe.

Boundary: it is still one carrier/context; it does not prove that this set is older, original, superior, or globally normative.

## 5. New source-reading lesson: Semantic-Object Type Safety

The QM-SRC-0022 probe exposed another failure mode.

Its OCR/text search finds tokens such as `白虎 / 玄武 / 朱雀` in more than one local method context. PDF p44, for example, visibly discusses `天将阴阳干支所属` and a twelve-general/deity context. Those lexical hits are not automatically evidence about the p22 Qimen eight-position sequence.

New reading discipline:

`TOKEN -> LOCAL_SECTION -> METHOD_OBJECT -> RELATION -> LINEAGE_CLAIM`

A familiar symbol name cannot identify its method role by itself.

Working name:

**Semantic-Object Type Safety**.

This is parallel to the project's existing:

- Sequence-Object Type Safety;
- Representation-Object Type Safety.

It is not yet promoted into a new top-level schema or theory version.
