## Full-book distillation summary

### A. The source is internally heterogeneous

The book contains multiple evidence/method layers, including:

1. source criticism / traditional history;
2. 三元 and standard plate setup;
3. 九星 seasonal/task interpretation;
4. 九星十二时辰应克;
5. 年家/月家/日家/时家 variants and 18 bureau lookup tables;
6. ritual/符咒/反闭/步斗/六戊/禁敌 materials.

The project must not flatten these into one universal rule pool.

### B. Setup choice is a first-order degree of freedom

The book distinguishes 平气/定气 and 正授/超神/置闰/接气. These choices must be declared before outcome feedback. Parallel variants require independent preregistration/scoring.

### C. Deity-system conflict is real

The source uses:

`值符 / 螣蛇 / 太阴 / 六合 / 勾陈 / 朱雀 / 九地 / 九天`

This conflicts with the modern 白虎/玄武 baseline. The project preserves the conflict rather than silently harmonizing it.

### D. 九星 is not source-internally reducible to one fixed label

The book has rough吉凶 categories but also conditions star use by season, task and旺相休囚. Fixed labels are therefore insufficient as verdicts even on the source's own terms.

### E. The 18 bureau tables are structurally valuable but not empirical proof

The lookup tables are visually explicit and mechanically auditable. Their reproducibility is `Lookup Determinism`, not predictive validity.

The first fixture pass itself exposed a main-reviewer semantic-association error: same-raster title visibility had been mistaken for table identity. Corrected table-body mapping and negative controls now preserve that failure history.

### F. Hour-omen doctrine must be isolated

`九星十二时辰应克` maps star/hour combinations to concrete future events and timing. It remains a separate prospectively testable method family.

### G. Ritual material is default-excluded

Incantations,符,禹罡/步斗,六戊,博奕胜负 and禁敌 methods are preserved as source evidence but excluded from ordinary prediction scoring and claims of empirical efficacy.
