## 8. Methodological lesson

An independent source is most valuable when it constrains an executable object, not merely when it repeats the same terminology.

Here the useful convergence is not “two books both mention 八神”. It is the combination of:

`center host + outer rotation object + worked timestamp + chief star/door + sparse palace placements`.

That is substantially harder for a wrong implementation to satisfy accidentally.
