# 八字学习笔记 01：基础理论（自我消化版）

> 材料来源：《滴天髓白话详解》（卓飞宏今注）、《八字精彩断语精选》、《男命桃花》
> 本文不是摘抄，是我用自己的话重新推导的理解。原文保留在材料库中供回查。
> ⚠️ 标记 = 存疑或各家有分歧，已记入「分歧台账」。

## 〇、学习方法（本轮定下的规矩）

1. **先理解后记忆**：每条规则先问"为什么是这样"，推不出来的不硬背。
2. **理论必须挂案例**：《滴天髓》每章附任铁樵实批命例，读理论时连案例一起读，案例是理论的"测试用例"。
3. **断语必须带前提**：所有古断语都省略了"身旺身弱"前提，用之前必须先补前提，否则就是乱套。
4. **实证优先**：《男命桃花》作者验证近百名风尘女郎命例，发现传统"桃花劫"应验者不过二三十位——古书结论要用案例检验，不能全信。
5. **分歧不回避**：各家说法打架时全部记下，弄清"为什么不同"，这是灵活应用的关键。

## 一、三元与天地人

- **天干**（天元）：主外、主动。用事之神在天干才显效——好比做事要被人看见、被认可。
- **地支**（地元）：主内、主静，是"根据地"。天干用神的旺衰取决于地支对它的支撑。
- **藏干**（人元）：地支里藏的天干，天地之间的具体承载。
- **顺逆总原则**：顺应用神则吉，逆用神则凶。天干气弱地支生之、地支气弱天干辅之，都是有情为顺。

## 二、旺衰判断（最难也最核心）

1. **不能只看月令**："得时俱为旺，失令便作衰"是死法。春木司令时，休囚的戊己土并未绝于天地；八字以月令为重，但年日时也有损益之权。
2. **根气重于天干数量**：天干得一比肩，不如地支得一余气墓库；得二比肩，不如支中得一长生禄旺。道理：比肩如朋友相扶，通根如家室可托——干多不如根深。
3. **得时不旺、失时不弱**：春木虽强，金太重而木亦危（干庚辛支申酉，无火制不富）；秋木虽弱，木根深而木亦强（干甲乙支寅卯，遇官透能受）。
4. **颠倒之理十条**（物极必反，旺衰判断的进阶关键）：
   - 木太旺似金，喜火炼；木旺极似火，喜水克。
   - 火太旺似水，喜土止；火旺极似土，喜木克。
   - 土太旺似木，喜金克；土旺极似水，喜火炼。
   - 金太旺似火，喜水济；金旺极似水，喜土止。
   - 水太旺似土，喜木制；水旺极似木，喜金克。
   - 太衰者宜生（木太衰似水宜金生）；衰极者反宜克泄（木衰极似土宜火生）。
5. **最高层次的视角**（卓飞宏）：断命的最高境界是跳出日主旺衰，直接把八字分成用神、忌神两派——用神能抗衡忌神就扶用神；用神太弱无根，就顺从忌神之势为己用。旺衰要看源头和流向。

## 三、体用与用神

- **体用**：日主为体（形象气局成格时以格象为体），用神为用。核心是"扶之抑之得其宜"。
- **变易**：旺则抑之，但旺到不可抑时反宜扶之（从强）；弱则扶之，但弱到不可扶时反宜抑之（从弱）。这是"不易中之变易"。
- **常规取用对照表**：

| 局面 | 取用 |
|---|---|
| 日主旺、印多 | 财星 |
| 日主旺、比劫多 | 食伤（通关生财） |
| 日主弱、官杀旺 | 印绶（化杀生身） |
| 日主弱、食伤多 | 印绶 |
| 日主弱、财星旺 | 比劫 |
| 日主与官杀两停 | 食伤 |
| 日主与财星均敌 | 印比 |

## 四、月令（提纲）

- 月令不受损可占命局约四成分量（卓飞宏估法，⚠️ 属一家之言，需案例验证）。
- **人元司令**：月内分日用事。如寅月：立春后七日前戊土用事，八至十四日丙火用事，十五日后甲木用事。⚠️ 各本分日天数有出入（有十五日/十八日两说），且雨水与惊蛰的交节衔接需注意，用时要核对万年历。
- 司令之神须得天干引助才有力：人元司令 + 天干透出 = 真神得用。

## 五、八格

- **取格流程**（任铁樵）：先观月令得何支 → 次看天干透何神 → 再究司令定真假 → 然后取用分清浊。月逢禄刃无格可取时，审日主喜忌另寻别支透干者借以为用。
- **正格七种组合**：官印、煞印、财煞、食神制杀、食神生财、伤官佩印、伤官生财。
- **变格**（从五行气势）：从财、从官杀、从食伤、从强、从弱、从势、一行得气、两气成形。
- **明确否定的外格**：飞天合禄、壬骑龙背、六阴朝阳、鼠贵格等——"何如生克制化之一理"。
- ⚠️ 分歧：卓飞宏说"八格就是十神：财官印分偏正 + 食伤比劫"，把比肩劫财也算进八格；而传统以月令定格，比劫（建禄月刃）不成格。我的判断：卓说偏教学简化，实操仍应按任铁樵的月令定格法，比劫只作帮身论。

## 六、官杀

- 官=正当约束、管理、传统、地位威望；女命为正夫。杀=偏激不羁、武职武略；为忌时代表打击伤害懦弱；女命为情人，但局中无正官时杀可作正夫。
- 身旺以杀为官，身弱以官为杀。
- 独杀乘权无制伏，职居清要；众杀有制且主通根，身掌权衡；杀生印生身，龙墀高步；身任财而财滋杀，雁塔题名。
- 杀重身轻，非贫即夭；杀微制过，虽学无成。
- **官杀混杂判断要点**：日主旺相可混，日主休囚不可混。去留原则：藏官露杀合官留杀、藏杀露官合杀留官，务求格局清。

## 七、断语方法论（来自断语集）

- **第一原则**：所有断语必须先补"身旺身弱"前提。
- 身旺：用官得官为官无官灾；用财得财富；忌印无印有学识名气；用食伤得食伤聪明多才艺。
- 身弱：用印得印有学识；用印且印得官生，大贵；忌官而官不见，为官；忌财而财不见，富。
- 加上组合与作用关系后更复杂（如身弱用印而官不生印：有工作无官），但"依理可推"，古断语也是这么推出来的。

## 八、桃花专题（男命桃花笔记的提炼）

- 男命以正偏财为异性：偏财多见/透干=风流多情；正财旺=好色重感官享受；正偏财交集=风流好色，身弱拈花惹草，身强金屋藏娇。
- 金水太旺多情风流；水太旺或太亏皆主多淫欲（水为忌者巧言善诈，带偏财更验）。
- 桃花喜静不喜刑冲会合；桃花带合且水多者更风流。
- 正官坐桃花福禄堪夸——官有约束力，自制力强。
- 查桃花：申子辰见酉，寅午戌见卯，亥卯未见子，巳酉丑见午（以年支或日支查）。
- 桃花年逢羊刃：防纷争损财；桃花年逢七杀：防因色生官非（女命更验）。
- **实证修正**：桃花劫（如寅午戌年冬月亥时生）古书断语很凶，但作者验证近百名风尘女郎，应验者不过二三十位——应验率不足三分之一，不可直接套用。
