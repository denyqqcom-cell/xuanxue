# 八字学习笔记 11：风集案例精读（第 96-99 页）

> 本轮学习模式：逆向工程——看宋英成如何复盘别人的断语，比直接读他自己的断语更能学到"推演链"。

## 一、廖太太案（肝癌）的应期技法

**已知**（前页命盘，此处记录技法不重复命盘）：
- 43 岁丁巳大运：运支巳与原命三刑逢冲，命中保护星受伤
- 庚午流年：冲年支子水羊刃，形成子午与寅申异组之冲
- **病位推演**：壬水绝在巳、病在寅，命中唯一的木受刑克——木主肝胆→肝癌
- 叠加星曜层：流年冲命宫、小限走壬午、岁破凶星入占、小限羊刃冲年柱
- 引用古赋："羊刃冲合岁君，流年遇此主灾，三刑七杀如交遇，必定阎王出引征"（渊海子平）

**值得记录的态度**：实际诊断是肝癌早期、癌细胞未蔓延，宋英成写"但愿我们在命理上的判断是错误的"——**命理判断与医学事实冲突时不嘴硬**。这种诚实是实证精神的范本。

**技法要点**：五行六神（木主肝胆）+ 冲合刑穿（三刑逢冲）+ 星曜（小限/命宫/岁破）三层叠加定应期；另有"夫妻磁波感应"说——曾提前数年警告廖先生 42-47 岁夫妻宜分开避灾（依据"时上偏财遇劫星……伤妻损妾多遭辱"诗赋）。

## 二、文相人七断复盘（四十二章，本轮核心）

**命造**：丙申 / 辛卯 / 甲戌 / 丁辰（男，1956 年生）
**背景**：另一位命理师广告宣称能从该八字看出七件事，但不说命理原因；宋英成逐条逆向推演。

| 断语 | 宋英成的推演链 |
|---|---|
| ①婚前有女友难成婚 | 年支申藏戊土偏财=婚前女友定位；申本气庚被月支卯中乙木所合=被更年轻的男性夺走 |
| ②第一胎流产/堕胎 | 子息星取月干辛金正官，被年干丙火合走（合化他物）；子息宫辰被戌冲、被申拱，有冲有合宫位动摇；辛金墓库在辰 |
| ③酒量甚佳 | 甲木生仲春"吸水本能强"（春木汲水），日坐戌燥土亦吸水；酒=水，吸水能力强=千杯不醉 |
| ④妻母难谐 | 印星气势强、财星只一点（戌中戊土又被辰合申冲）→财印交战=婆媳不和；父母宫卯为劫财羊刃加重矛盾 |
| ⑤妻与年轻男人私奔 | 无正财只有偏财（妻星不正）；妻宫戌被辰冲又被卯合且卯戌化火=劫财合妻宫化成别物；甲午运午合戌、丙寅年寅午戌火局把妻宫戌整个引拔走；丁卯年卯为桃花（寅午戌桃花在卯）+羊刃桃花合出妻宫 |
| ⑥26 岁辛酉年先上车后补票 | 申酉戌三会西方金+辰酉合，子息宫妻宫同时感应；辛酉为天透地藏的子息星→奉儿女之命结婚 |
| ⑦29 岁甲子年迁出父宅 | 岁运双甲克戊土偏财（父星）同性尽克；甲子刑父母宫卯（无礼之刑）；子冲大运午；申子辰合水局牵动父母宫 |

**我的评估**（哪些可复用、哪些存疑）：
- ✅ 可复用："星宫同感"原则——流年同时感应星（十神透干）与宫（地支宫位）时事件发生概率最高（⑥的用法）
- ✅ 可复用：偏财为父、财印交战主婆媳不和、劫财合妻宫化他物主婚变
- ⚠️ 存疑：子息星取**正官**（辛），与常见"男命以七杀为子、正官为女"相反——门派差异，入分歧台账
- ⚠️ 存疑："女友被年轻男性夺走"靠卯中乙木=劫财且卯为少阳的联想链，灵活但难以标准化复现
- 💡 创新类比素材："酒=水，吸水能力=酒量"——类化表新增条目

## 三、方法论金句（原话摘录，与"灵活变通"哲学完全一致）

1. 文相人（宋英成转述并认同）："论命没有什么诀窍可寻，只要活用演绎与归纳及合乎逻辑的推理，再配合自我意识的无限膨胀，那么诀窍穷则俯拾皆是。"
2. "诀窍就靠自己来开发。"
3. **宋英成自述**："命理学上没有一个放诸四海皆准的程式，也就是说没有绝对事项。比方说，与上面这个命造同一时辰出生的人，不一定就会在廿六岁那一年结婚……命理只是由归纳到演绎上的一种统计学，但尚会受到地理环境、风俗习惯、种族差异、先人祖德、政治制度、教育品格这些影响。"
4. "因此我们要研究这门古老的学问，若没有现代的科学精神与逻辑推理之观念，想要在仿似迷魂阵中闯出一条康庄大道是死路一条。"

→ 这四条直接支持我 V2 方法中"预测留置信区间、断语标注适用边界"的设计，也支持自创理论路线：**统计归纳出的规则必须承认例外，例外的来源就是新理论的入口。**
