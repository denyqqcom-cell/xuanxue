# 八字学习笔记 02：诸家交叉比对（自我对照表）

> 比对对象：《滴天髓白话详解》（任铁樵注 + 卓飞宏今注） vs 梁湘润《子平基础概要》
> 目的：同一概念在不同体系中的说法差异，弄清"为什么不同"，这是灵活变通的基础。
> 我的立场：不站门派，看哪家方法更可操作、更符合实证，就用哪家；矛盾处全部记录。

## 一、日主强弱：定位之争

| 维度 | 任铁樵（滴天髓） | 梁湘润 |
|---|---|---|
| **优先级** | 察衰旺是论命枢纽："察其衰旺，究其顺悖" | 只是"入门优先"，不是论命唯一优先；"日后终身困于扶抑日主的小范围"是警告 |
| **与调候关系** | 未明言先后 | 明确说：调候用神优先于日主强弱。例：丙日主生酉月，不得令，仍以壬水为第一优先，"缺水则全盘皆墨" |
| **操作方法** | 看根气轻重、生克泄耗、颠倒之理 | 单式（得令、得地、得党）→ 复式（投票式：三干四支逐一计正面/负面票） |
| **结论观** | 旺衰决定扶抑方向 | "只要不过分强或极弱，并非唯一最重要之事"；地支有根（藏干有比劫）就弱不到不可扶 |

**我的消化**：两家其实不矛盾——任铁樵站在"判断之后怎么用"的高度（衰旺是取用的依据），梁湘润站在"初学者别钻牛角尖"的角度（先会判，但别以为判完就结束了）。我采纳的操作顺序：
1. 先用梁湘润的投票法快速定性（单式三步 + 复式计票）
2. 再用任铁樵的根气理论修正（干多不如根深、得时不旺失时不弱）
3. 最后看调候——寒暖燥湿有时一票否决

## 二、复式投票法实例（梁湘润原例，我已重推验证）

**八字**：己未 / 丙寅 / 甲子 / 庚午（甲日主，生寅月）

| 柱 | 干支 | 对甲日主的作用 | 票 |
|---|---|---|---|
| 年干 | 己 | 我克之财，耗力 | 负 |
| 年支 | 未 | 火库，木所生，耗力 | 负 |
| 月干 | 丙 | 食神，泄秀 | 负 |
| 月支 | 寅 | 甲之禄位 | 正 |
| 日支 | 子 | 水生木 | 正 |
| 时干 | 庚 | 七杀克身 | 负 |
| 时支 | 午 | 火泄木 | 负 |

**计票**：2 正 vs 5 负 → 虽月令建禄，仍判"日主不够强"。
**我的验证**：与任铁樵"春木虽强，金太重而木亦危"完全呼应——庚金七杀透干、午火泄秀，建禄也不足以敌。两家方法殊途同归。

## 三、用神：一词五义（梁湘润的拆解）

| 名称 | 定义 | 适用场景 |
|---|---|---|
| 格局用神 | 顺用逆用的用神 | 八格成败 |
| 通关用神 | 破格时的调节 | 五行交战 |
| 病药用神 | 调候忌神的对治 | 寒暖燥湿失衡 |
| 专旺用神 | 从旺从势特别格 | 一气专旺 |
| 调候用神 | 十干对十二月支 | 气候优先 |

**对照**：《滴天髓》讲"用神"基本指扶抑+调候两种，梁湘润拆成五个，避免混淆。这是学习时的关键提醒：别人说"用神"时先问是哪种。

## 四、神煞：两派尖锐对立

| | 任铁樵 | 梁湘润 |
|---|---|---|
| 态度 | "吉凶神煞，乃好事妄造，非关命理休咎" | "在子平法占有相当比重的特征" |
| 理由 | 以五行生克一理统之 | 提供了一套应期规则：年=幼年、月=青年、日=中年、时=晚年 |

**梁湘润神煞五条应期规则**（可操作，我采纳为辅助工具）：
1. 神煞在年主幼年、月主青年、日主中年、时主晚年
2. 带三合六合 → 效应期延伸
3. 坐空亡 → 吉凶减半
4. 坐禄作强势、坐绝接近没有
5. 坐空亡又带合 → 恢复原特征

**我的消化**：任铁樵反对的是"专以神煞论命"，梁湘润用的是"五行为主、神煞为辅、定应期"。实证立场：神煞不作吉凶主判，只作应期与象义辅助；《男命桃花》的实证（桃花劫应验率不足三成）也支持"不作定论"。

## 五、明确否定的流行做法（两家共识 + 分歧）

**两家都否定**：
- 各种外格奇局（壬骑龙背、六阴朝阳、飞天禄马等）
- 加减百分比量化日主强弱（梁湘润明言"不符合先贤子平法的途径"）
- 执着长生十二宫的生死败绝（任铁樵："不足凭"）
- 墓库逢冲必发（任铁樵："谬也"）

**分歧保留**：
- 神煞（见上）
- 调候与扶抑的优先级（梁湘润高调候，任铁樵未明言先后）

## 六、本轮学习方法复盘（自我验证的结果）

1. **交叉比对有效**：梁湘润的投票法实例，用任铁樵的根气理论重推，结论一致——说明方法可互相印证。
2. **分歧处不强行调和**：神煞问题两家就是对立，我把两派规则都记下，标注适用边界，实战中按"主判用五行、辅助用神煞"执行。
3. **创新点初现**：把投票法做成可复用检查表（每次排盘后逐项打钩计票），把五类用神做成标签（写批语时先标用神类型），避免概念混淆。
