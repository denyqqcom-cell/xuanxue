# 八字学习笔记 05：盲批实战记录（自我验证）

> 方法：取《滴天髓白话详解》任铁樵亲批命例，**遮住原评**，用我卡片里的「五步法」独立推导，再对照原评检验。
> 目的：验证我的学习框架能否复现高手的判断；推导错误处就是框架漏洞，回去补理论。

## 命例一：董中堂造（庚申 / 庚辰 / 戊辰 / 戊午）

### 我的独立推导（五步法）

1. **看月令**：戊土生辰月（季春三月）。辰为湿土、水库，春土虚而不实——不得令之旺，只是有余气。
2. **看根气**：戊坐辰（湿土）、年柱戊申、时支午火。表面根多，但申辰有拱合水局之势，辰土湿性被引动，根气打折扣。
3. **看党众**：年干庚金食神两透泄身，申金当令之泄；四柱无一点木来疏，无明火透干（午藏支中）。生扶者少（仅午火印星）、泄耗者众（两庚+申+辰中癸水暗藏）。
4. **看合冲**：申辰半合水（财局）泄身之气；午火被辰土晦、被庚金所隔，力量受限。
5. **定旺衰取用**：日主被两庚狂泄、申辰引水，属"过泄"偏弱，取午火印星为用——既扶身又止泄。忌水木再来（水为财坏印，木虽克土但在此局官杀虚浮不若印实在）。

**结论**：用神在午火印星，喜火土，忌水。

### 对照原评

> "日干戊土，生于季春午时，似乎旺相，第春时虚土，非比六九月之实也。且两辰蓄水为湿，足以泄火生金，干透两庚，支会申辰，日主过泄，用神必在午火。喜水木不见，日主印绶不伤，精神旺足，纯粹中和……直至子运会水局不禄。"

**验证结果**：✅ 完全一致。
- 我判"春土虚、过泄、用午火、忌水"与原评逐条吻合。
- 原评补充的信息：子运（水运）会水局，印星被坏而亡——印证"忌水"的判断延伸到大运层面同样成立。
- **框架得分**：五步法在此例无漏洞。

## 命例二：同邑王姓造（壬辰 / 壬寅 / 甲寅 / 庚午）

### 我的独立推导（五步法）

1. **看月令**：甲木生寅月（孟春），得令，甲木司令正当权。
2. **看根气**：甲坐寅、月支寅——双坐禄旺，根极重。
3. **看党众**：两壬水透干生木，辰为水库蓄水养木；全局水木成势，党众极盛。
4. **看合冲**：无合冲伤根。庚金七杀透时干，但寅月金处绝地，坐午火受克，又被壬水泄——庚金休囚已极。
5. **定旺衰取用**：日主旺极，水木一气成势。此时若取庚金七杀制身，是以卵击石，反激其怒；依"旺极宜泄不宜克"之理，当顺其气势，用午火食伤泄秀为用。

**结论**：用午火泄秀，忌金水逆势（金生水更增病），木火运吉。

### 对照原评

> "俗以身强杀浅论，取庚金为用，谓春木逢金，必作栋梁之器，劝其读书必发；至三旬外，不但读书未售，而且家业渐销……一点庚金，休囚已极，且午火敌之，壬水泄之，不惟无用，反为生水之病。大凡旺之极者，宜泄而不宜克，宜顺其气势，弗悖其性也。以午火为用……彼即弃儒就经营，至丙午运，克尽庚金之病，不满十年，发财十余万。"

**验证结果**：✅ 结论一致，且暴露了一个关键陷阱。
- 原评记载当时"俗论"取庚金为用（"春木逢金，必作栋梁之器"是流传甚广的漂亮话）——这是**套断语的典型错误**：没有判断庚金在寅月的实际状态（绝地、受克、被泄）。
- 我的五步法第 4 步"看合冲/干支状态"正好拦住了这个陷阱：庚金的状态由月令和坐支决定，不是一句口诀能定的。
- **框架得分**：五步法在此例也站得住；"旺极宜泄不宜克"（颠倒之理）是关键分水岭。

## 本轮验证总结

1. **两例全部复现原评结论**，五步法框架初步可用。
2. **命例二验证了一个重要学习原则**：口诀断语（春木逢金作栋梁）不结合干支实际状态就会出错——与《男命桃花》实证、断语集"须补身旺身弱前提"三处材料相互印证，"自我验证、不迷信书本"的方法论成立。
3. **框架待补漏洞**：五步法目前只覆盖原局静态分析，尚未纳入大运流年的动态验证——下阶段用《大流年批导法》和命例的大运记录补上。
