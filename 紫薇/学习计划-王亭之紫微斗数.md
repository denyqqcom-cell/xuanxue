## 学习路线（七阶段）

### 第一阶段：筑基入门（预计 2-3 周）

**目标**：建立紫微斗数的基本框架认知，能看懂命盘、识得主要星曜与宫位。

**核心材料**：
- 《紫微入门》全文（已有精读笔记）
- 《斗数全书》卷壹~卷贰的赋文部分（太微赋、形性赋、星垣论）

**学习内容**：
1. 十四主星的五行、强弱分类、型格、事态密码、象意、疾病对应
2. 六吉星、六凶星、禄存、天马等辅星助星的基本性质
3. 十二宫位的含义与看命程式
4. 天干四化表（至少背熟甲~癸十干的化禄/化权/化科/化忌对应星曜）
5. 三方四正的概念与力度比例（70:30 / 60:40）
6. 太微赋、形性赋的纲领性论断

**检验标准**：
- 能默写十四主星性质表
- 能说出任意天干的四化对应
- 看到一张命盘能识别各宫位主星并给出初步判断

**产出**：
- [x] 《紫微入门》精读笔记 ✅
- [ ] 《斗数全书》精读笔记（进行中）

4. 王亭之对传统赋文的独特注解与修正观点
5. 中州派对"庙旺利陷"的态度（对照《紫微入门》"行流运无庙陷之分"）

## 学习方法建议

1. **文字版优先**：先读完所有可直接提取文字的典籍（约900页），建立框架后再攻克扫描版
2. **笔记驱动**：每读完一本书必须产出结构化笔记，不追求速度追求消化
3. **交叉验证**：同一知识点在不同书中的表述要对照比较，标注分歧
4. **实例为王**：从第二阶段开始就要配合实盘练习，避免纯理论空转
5. **OCR 按需**：扫描版不要批量 OCR，用到哪本再处理哪本，控制成本
6. **记忆沉淀**：关键知识点（四化表、格局条件、力度比例等）写入长期记忆，供后续会话调用
