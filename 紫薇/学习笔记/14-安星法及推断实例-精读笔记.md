## 二、安星法核心要点

### 2.1 起紫微口诀（与初级讲义完全一致✅）

```
六五四三二，酉午亥辰丑。
局數除日數，商數宮前走。
若見數無餘，便要起虎口。
日數小於局，逕直宮中守。
```

**交叉验证**：此口诀在初级讲义(p.35-36)、全集一(p.27说明)、本书(p.36-37)三处完全一致。这是王亭之体系中**最稳定的知识点**。

### 2.2 安天府镜像关系（图解确认✅）

書p.44圖六清晰展示：紫微与天府以寅-申轴为对称轴镜像分布。寅申同位，其余斜对。与闭关遗留三问解答完全吻合。

### 2.3 紫微系 vs 天府系排列方向

- **紫微系**（紫微→天機→太陽→武曲→天同→廉貞）：从紫微位置**逆时针**排列
- **天府系**（天府→太陰→貪狼→巨門→天相→天梁→七殺→破軍）：从天府位置**顺时针**排列

書p.45兩幅完整命盤圖示確認此規則。

### 2.4 掌诀的实际价值 > 查表

王亭之明确说（p.28-29）："口诀和掌诀是为初学者学习安星法而设，其实际价值大于表格。" 这与奇门遁甲中"口诀查原文，记忆不配当证据"的纪律形成有趣对照——紫微这边反而鼓励内化口诀到掌上。

### 2.5 流年星曜不安入命盘

註二（p.28）：所有流年星曜（流昌、流曲、流羊、流陀及流四化）**不写入命盘**，推算时在心中安布。这是中州派与其他流派的重要操作差异。

## 三、推断法核心要点

### 3.1 批判过度复杂化（极重要独立观点🧠）

王亭之在推断法前言（p.110-111）中严厉批评：

> "紫微斗數的推斷法本來非常樸實，只是近年來卻花樣百出，以至弄到各宮各有四化，又有「父母宮之疾厄宮」、「子女宮之事業宮」等等，實緣木識推斷要領，於推斷失準時便挖空心思圖補救之故。誰知愈補救愈複雜，便弄到支離破碎，矛盾叢生。"

**与奇门认知体系的呼应**：奇门知识库也反复强调"切忌机械套用公式"（善天道p.83）。两个体系的核心大师都在反对同一件事——把简单架构复杂化来掩盖推断能力的不足。

### 3.2 中州派推断架构（朴实三层）

1. **推大运**：以大运所在宫位为命宫，逆布十二宫，流曜根据命宫干支安布
2. **推流年**：以年支所在宫位为命宫，同样逆布十二宫，流曜根据年干支安布
3. **流月/流日/流时**：同理递推

### 3.3 借星安宫两大关键秘法（中州派独家🧠）

王亭之自称"古人从来不肯轻传的一秘法"（p.125）：

**关键一**：借星安宫时，必须将对宫的**全部星系**借入，不仅限于正曜。

**关键二**：寻找三方四正时，如果其中任何一宫无正曜坐守，该宫仍须向其对宫借星安宫，然后才与本宫会合。

**实例验证**（p.124-125）：某男命夫妻宫在辰无正曜→借戌宫全部星系→再看子宫只有文曲非正曜→借午宫天同太阴铃星擎羊→最终判定"四煞并照"+天机化忌+天梁天同太阳化科巨门→婚姻极不完美但太阳化科加巨门维持面子→怨偶不轻易言离。

### 3.4 基本术语33条分类体系（比初级讲义更细）

| 编号 | 术语 | 内容 | 与初级讲义差异 |
|------|------|------|---------------|
| (1) | 正曜 | 十四主星 | 一致 |
| (2) | 輔曜 | 左辅右弼天魁天钺 | ⚠️初级讲义将魁钺归入"六吉星"，此处单独列为"辅曜" |
| (3) | 佐曜 | 文昌文曲禄存天马 | ⚠️初级讲义将昌曲归入"六吉星"，此处单独列为"佐曜" |
| (4) | 煞曜 | 火铃羊陀（四煞），加空地劫称六煞 | 一致 |
| (5) | 空劫 | 地空地劫 | 一致 |
| (6) | 化曜 | 禄权科忌 | 一致 |
| (10) | 桃花諸曜 | 红鸾天喜咸池大耗天姚沐浴；**廉贞贪狼虽具桃花性质但入正曜系列** | ⚠️重要区分 |
| (27) | 殺破狼 | 七杀破军贪狼永远三方相会，命运转变枢纽 | 初级讲义未单列此术语 |
| (33) | 借星 | 本宫无正曜则借对宫，推大限流年流月皆需用 | 初级讲义提及但未展开两大关键 |

**关键发现**：辅曜(魁钺)与佐曜(昌曲禄马)的分离是本书独有的精细分类。初级讲义笼统称"六吉星"，本书拆成两组，暗示它们的性质和作用机制不同。

## 四、推断实例摘录（命例清单）

### 命例1：溥仪（末代皇帝）— 有已知结局✅

- **生辰**：书中未明确给出具体生辰，但命盘图可见
- **命宫**：太阳巨门在申宫
- **关键分析**：
  - 日生人太阳为中天星系主星，喜百官朝拱
  - 经借星安宫后，朝拱星计有五对（左辅右弼、文昌文曲、三台八座、龙池凤阁、台辅封诰）→合百官朝拱条件
  - 太阳居申=日落西山，仍有地位但不持久
  - 禄权科会增加贵显
  - 太阳巨门+天马+羊陀照射+廉贞阴煞孤辰寡宿→六亲缘薄、易于流离
  - 福德宫机梁+天马+昌曲辅弼→好学不专一、游移不定→"对打乒乓球都有过深厚兴趣却一无所精"
- **结局**：已知历史事实，完全吻合
- **验证价值**：⭐⭐⭐ 历史人物，结局确定，可盲推验证

### 命例2：某女士 — 部分已知结局

- **命宫**：天机太阴+天马
- **关键分析**：
  - 天机太阴已属变动不定，更见天马→浮动性极强
  - 财帛宫天同陀罗，事业宫天梁化禄→可能人生飘荡或仅思想波动
  - 父母宫文昌文曲左辅右弼但有擎羊天魁+红鸾咸池→父母有教养但有桃花
  - 田宅宫科文诸曜毕集+桃花曜重+武曲化忌同破军→早年丧母、父亲续娶、数载无嗣
  - 父母宫田宅宫都有火铃照射+命宫天马→少小离家（现代=留学）
  - 福德宫巨门落陷+羊陀照+太阳太阴天机天同浮动混合→学而不实、半途而废
- **结局**：书中暗示"得力于田宅父母二宫之吉，若不佳则个性受不良熏陶"
- **验证价值**：⭐⭐ 匿名但分析详细，可部分验证

## 六、值得注意的中州派独家观点

1. **借星安宫两大关键**：自称"古人从来不肯轻传"，是中州派推断准确性的核心技术
2. **辅曜vs佐曜分离**：魁钺与昌曲禄马性质不同，不应笼统归为"六吉星"
3. **批判过度复杂化**：各宫各有四化、宫中之宫等做法是"补救失准"的产物，越补越碎
4. **流年星曜不入盘**：操作层面与其他流派的重要差异
5. **掌诀价值>查表**：鼓励内化而非依赖工具
