## 一、书籍定位与内容概览

本书为紫微斗数**入门级教材**，面向零基础或初学阶段的学习者。全书以"论命要旨"开篇，系统介绍十四主星、辅星助星、十二宫位、天干四化、看命程式，以及各星曜在十二宫的逐一论断，最后附宫干四化飞星法与阳宅对应。语言简练、条目清晰，适合作为**第一本通读教材**。

书中明确提到派系差异（透派、综合派、隔山派、中州派），并指出各派在起大运方式、定五行局方式、天干四化星、看盘重点、宫位意义上均有不同（第1页）。本书所载四化表标注"依师传之一种"（第43页），属于某一传承体系，非唯一标准。

## 四、专题论断口诀/规则汇总

### 4.1 事业/学业（第1页）

1. 看流十年四化在何宫位，流命宫三方四正可见
2. 化忌星在命 → 凶多吉少
3. 化忌在三方四正、化禄在命 → 吉多凶少
4. 化忌+擎陀火铃 → 急剧破败
5. 化禄+擎陀火铃 → 急剧成功
6. 杀破狼格局 → 急成急败
7. 上下两层星盘天干地支伏吟 → 力量加倍
8. 六合宫位之星会有影响
9. 命宫无主星 → 行辛劳之运（不论成败）
10. 禄逢冲破 → 吉里藏凶
11. 事业宫有化忌 → 不宜打工；财帛宫有化忌 → 不宜做生意

### 4.2 钱财（第2页）

1. 看钱财要加看田宅宫（田宅为库为后门，看积财力）
2. 田宅宫见化忌及冲动 → 积财力大打折扣，到底成空
3. 横财：杀破狼及廉贞可视为偏业/横财，其他为正行正业正财
4. 流十年命宫或田宅宫不可见破或化忌，否则虚花
5. 田宅宫无破或化忌 → 置业可化解
6. 流年命宫/田宅/财帛见化禄+三方四正会见杀破狼或廉贞+擎陀火铃 → 得急财或横财（不见化忌为合）

### 4.3 疾病/灾难（第2页）

1. 先天命宫及疾病主星 → 慢性病类别
2. 流十年命宫及疾病主星 → 该十年慢性病类别
3. 以上宫位见化忌+凶星 → 急病；化忌双见+凶星云集 → 病死
4. 迁移宫见化忌+凶星 → 出外受灾；三方四正无救+凶星 → 凶亡
5. 身宫受刑冲化忌+六凶 → 身体急剧损伤（擎陀夹忌会死亡）
6. "铃昌陀武"+化忌在命宫/身宫会照 → 急剧大灾劫（死亡）
7. 最忌擎陀夹宫 → 应劫之时

### 4.4 婚姻（第3页）

1. 大运流年命宫三方四正见红鸾/天喜/咸池/大耗 → 桃花及异性机遇
2. 流运夫妻及三方四正见化禄/红鸾/天喜/咸池/大耗 → 婚喜（须本人愿意）
3. 已婚又见以上星曜 → 避忌婚外情
4. 已婚夫妻宫会见禄 → 可有婚外情；再加会忌 → 处理上有问题
5. 一人命宫三方四正所见星曜，很多时也在配偶命宫三方四正见到

### 4.5 移民（第2-3页）

1. 流十年田宅宫见破 → 移民永不回头
2. 流十年田宅宫不见破反见化禄 → 假移民（太空人）
3. 动能星：杀破狼、天机、天马、化禄
4. 流年/流月田宅宫见破 → 可能只是"今天不回家"

### 4.6 官非/争讼（第2页）

1. "刑囚夹印"：命宫见天相化忌+擎羊+廉贞会见或夹拱；或命宫见廉贞化忌+擎羊+天相会见或夹拱
2. 田宅宫冲破+命宫/身宫会擎陀夹忌 → 失自由（牢狱、绑票）
3. 文昌/文曲化忌在相关宫位 → 文件差错，小心合约

## 七、值得注意的特色观点

1. **派系差异明示**：开篇即列出透派、综合派、隔山派、中州派的五点差异（起大运、定五行局、四化、看盘重点、宫位意义），提醒学习者注意派系归属（第1页）。
2. **"铃昌陀武"死亡组合**：铃星+文昌+陀罗+武曲+化忌在命宫/身宫会照，主急剧大灾劫（死亡），这是极为凶险的组合标记（第2页）。
3. **田宅宫的核心地位**：论钱财必看田宅（库/后门），论移民必看田宅，论生死亦参田宅，田宅宫在全书论断中的权重极高。
4. **四化飞星活盘法**：将十二宫互为体用（如兄弟=财帛之田宅），通过宫干四化飞星看出深层因果关系，是高阶论命的核心技术（第45-55页）。
5. **阳宅对应**：将星曜与居住环境直接挂钩，体现了斗数与风水的交叉应用，这在一般入门书中较少见。
6. **力度比例量化**：给出自宫/对宫70:30、对宫/三合60:40等具体比例，为论断提供了量化参考框架（第44页）。

## 八、原文有价值段落摘录

> "紫微斗数论命，是用主人翁出生之资料，起出'星盘'（先天盘），总的星曜有一百多粒来推算命运；主要是引用其中'十四主星'、'辅星'、'助星'、'天干四化星'来批命。"（第1页）

> "先天命盘为体（具体骨干），流十年三方四正局势为用。原命盘只属静态、平面，要靠流十年因素'带动'。流十年层次属至高无上。"（第44页）

> "注意流四法从何宫打出，而该宫即是来龙，再看该四化带动/飞落另宫，是何名目，即知去脉（结局）。"（第44页）

> "主星控制大局，辅星左右大局。"（第44页）

> "行流运无庙陷之分。"（第44页）——这一条与部分强调庙旺利陷的流派形成对比，值得留意。
