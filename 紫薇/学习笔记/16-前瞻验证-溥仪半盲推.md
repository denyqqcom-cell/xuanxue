- **命宫**：太阳、巨门在申宫（太阳居申为日落西山）

## 二、我的独立推断（写于对书/对史之前，🧠层，附推理链）

### 第1层 态势
- 太阳巨门在申：巨日格而太阳日落。**太阳主贵、主名、主父、主公共性；落陷则贵气有名无实、光辉不能持久**。巨门主暗、主隔阂、主口舌是非。组合关系判定为【转化】：巨门之暗侵蚀太阳之贵 → "贵而见暗"，一生名誉与阴影纠缠。
- 五对对星百官朝拱：**格局的"架子"极贵**——但架子是别人给的、不是自己挣的（对星主仪仗、主排场，不主实权）。
- 底色判词：**生来带贵名，而贵名必被剥夺；一生在"被抬举"与"被抛弃"之间摆荡。**
- 核心短板：太阳落陷+孤辰寡宿 → 六亲缘薄，靠山皆不可恃；巨门+羊陀 → 易卷入是非、受制于人。

### 第2层 触发（结合时代，情境变量：帝制终结之乱世）
- 幼年大限即逢贵名之立与被夺（太阳落陷主"先得后失"）。
- 太阳主"父/君"，落陷见暗 → **其"君父"身份本身就是阴影的来源**：身份带来的是傀儡之实而非君主之权。
- 天马+机梁借入福德 → 一生迁移动荡，居无定所，且动荡出于外力。

### 第3层 投射（时代映射：1906-1967 中国）
1. **有名无实的最高头衔**：会登基或获得极高名位，但实权始终在他人之手（日落之太阳=挂名之主）。
2. **一生多次被"抬上去"又"摔下来"**，且每次摔落都由外部势力主导（贵气来自对星=他人仪仗，非自身能量）。
3. **漂泊离散**：居所多次被迫迁移，中岁有一段最暗时期（巨门之暗+羊陀+受制）。
4. **六亲缘薄、婚姻不稳**：亲情与配偶关系多离散。
5. **好学多艺而不专**：对星多主兴趣广、有文艺气质，但太阳落陷不主成就 → 晚年以普通人身份了结，反得平安。
6. 寿元：太阳落陷不主早夭，福德机梁有寿星之象 → **可享中寿以上**。

## 四、归因与诚实拆解（关键）

方向全中不等于框架全对。逐条拆解运气与真本事：

1. **真本事**：「太阳落陷=贵而有名无实」「对星=他人给的仪仗」两条转译是框架第1层"组合效应四关系"的真实产出，且推出了"傀儡"这一书中未明说的结构性结论（书只说贵显，未说权力来源）。
2. **真本事**：「先贵后失、外力主导」来自太阳落陷+天马的投射规则，非背书。
3. **运气/常识污染**：溥仪是历史名人，我的"常识"里存着他的一生。所谓"对历史核对"无法排除我写推断时潜意识已受史实影响——**这正是"半盲推"的天花板**。6/6 的命中率里有相当成分是这个实验设计本身无法剔除的。
4. **框架边界确认**：帝制终结、伪满、特赦这些**形态**完全由时代决定，盘面只给了"贵名被夺、漂泊、受制"的**势能**。v0.1第3层"投射"规则在此例中得到正向验证：势能×情境=形态。
