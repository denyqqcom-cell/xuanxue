## 二、核心理论提炼

### 2.1 丧星与害星分类（p10，全书理论基石）

**丧星**（主死亡、丧命）：太阳、太阴、天魁、地劫、天虚、截空、天哭
**害星**（主恶意、伤害）：七杀、破军、火海、火星、天钺、天刑

> 📖 这是王亭之自创的凶灾分类体系，不见于古赋或入门书。丧星偏"被动受害"，害星偏"主动施害"。

### 2.2 车祸星化对照表（p80，第二章核心工具）

| 星曜 | 遇凶星时的伤害类型 |
|------|-------------------|
| 天刑 | 受伤 |
| 破碎 | 全身粉碎 |
| 天机 | 脑破裂 |
| 武曲+天相 | 四肢断裂 |
| 天府+武曲 | 肠胃受伤 |
| 廉贞 | 大量出血 |
| 太阳 | 眼睛受损 |
| 天梁 | 骨折 |
| 紫微+破军 | 头部受伤 |
| 地劫 | 断腿 |

> 📖 此表为本书独有，将星曜性质与具体身体伤害对应。需注意：这是"遇凶星时"的条件性对应，非绝对。

### 2.3 巨门路况星化表（p100）

| 同宫星 | 路况含义 |
|--------|----------|
| 天虚 | 路面不宽 |
| 破碎 | 道路崎岖不平 |
| 擎羊 | 争先车道 |
| 封诰 | 相撞 |

> 📖 巨门被定义为"路况星"——因天虚、破碎、封诰同宫时，所发生事情必因路面崎岖狭小、争抢车道以致撞及计程车。

## 三、王亭之独立观点（逐条标注来源页）

1. **"丧星害星"二分法是本书独创**（p10）：古赋和入门书均无此分类，是王亭之为凶灾专题建立的专属分析框架。与初级讲义的"四煞六吉"分类不同，这里按"致死vs致伤"重新归类。

2. **巨门=路况星**（p100）：将巨门的"暗/隔阂"性质转译为交通场景中的"路面状况"，是情境推演的典型示范——同一颗星在不同事项中扮演不同角色。

3. **星化对照表的条件性**（p80）：所有伤害类型都标注"遇凶星时"，说明王亭之意识到单星不能定吉凶，必须看组合。这与v0.2框架的"组合效应四关系"完全吻合。

4. **推断逻辑链：命宫→身宫→大限→小限→流年**（p25/p55/p60等多处）：每个案例都遵循"先看本命格局底色→再看行运触发点→最后定位应期"的三层结构，与v0.2的"态势→触发→投射"高度一致。

5. **示意图vs真实命盘的区分**（p15/p30等）：书中明确使用"示意图"展示概念模型（如"凶星互冲"），与真实命盘案例分开。这说明王亭之有意区分"理论抽象"和"实战具体"。
