## 一、两篇文献性质确认

### 1.1 《骨髓赋与女命骨髓赋》——斗数四书之二（王亭之著作）

**性质**：这是王亭之"斗数四书"系列的第二卷，内容为《骨髓赋》及《女命骨髓赋》两篇古赋的中州派注释。总序中王亭之交代了全部著作体系：

| 著作 | 性质 |

| 《紫微斗数讲义》三册 | 陆斌兆编著，王亭之补注（入门） |
| 《王亭之谈斗数》一册 | 随笔杂谈（入门） |
| 《王亭之谈星》一册 | 星曜专题（入门） |
| 《安星法及推断实例》一册 | 起盘实操+实例（入门） |

| 《中州派紫微斗数》（深造讲义） | 推断秘诀+紫微星诀六百韵融化（进阶） |

**关键发现**：
- 注释依据"八喜楼钞本"，与坊本不同

- 钞本年代由明末以迄清初
- 王亭之明确说："凡真者必平易，而伪者必支离，一陷支离，则多掩饰，于是变为深渫奥"

### 1.2 《星曜飞躔十二宫吉凶反应的研究》——王亭之著作

**性质**：署名"[王亭之 | 中州派紫微斗数]"，是王亭之对十四正曜逐一详论其飞躔十二宫时不同反应的系统研究。

**核心比喻**："一个星曜，好似一块塑胶，每一个宫又好似不同的模型，所以星曜飞到某一宫时，其外型便被该宫的模型所改变，可是它的本质并没有改变。"

**结构**：按十四正曜逐一展开，每颗星下分十二宫（命宫、兄弟宫、夫妻宫、子女宫、财帛宫、疾病宫、迁移宫、交友宫、事业宫、田宅宫、福德宫、父母宫）详论。篇幅极大（94902字/1537行），是王亭之最详尽的单星逐宫论著。

## 二、《骨髓赋》核心赋文摘录与王亭之注解要点

### 2.1 发论部分

**原文**："太极星躔，乃群宿众星之主；天门运眼，即扶身助命之原。在天则运用无常，在人即命有格局。"

**王亭之注解要点**：
1. "群宿众星"的分布以紫微为主，构成先天格局
2. 先天星盘不是一成不变的，运限推移即后天变化
3. **这两点原则否定了专依"三方四正"来推断的程序**——看三方四正只是入门基础，推断必须看先后天变化
4. 例：先天命宫巨门在午，行经武曲七杀大限→必须以"巨门行经武杀"的先后天概念推断，而非光看武杀三方四正

### 2.2 "时同路同车不同"——先后天本质反应法

**王亭之独创比喻**：
> "这有如两架不同的车，同时驶经一条公路，但由于车的性能有异，所以在路上的驾驶情况便亦不一样。"

- 先天命宫巨门在午的人行经武杀大限 = 以"巨门在午"的本质际会"武杀在酉"的环境
- 先天命宫天相在未的人同样行经武杀 = "天相行经武杀"，反应不同
- **即使同年同月生，武杀宫垣三方四正大部份相同，际遇则绝对不一**

### 2.3 "先明格局，次看恶星"

**王亭之注解**：
- 先看命宫是否入格，无论是否入格均应继看煞忌刑耗
- 入格者提防恶星破坏；不入格者看恶星影响
- 有时恶星相会反而彼此削弱（如擎羊遇火星、陀罗遇铃星）
- 吉星亦会忽然变恶星（如武曲化忌最妨与文曲同会）

### 2.4 "斗数推断非宿命"

**王亭之注解**：
- 斗数推算的是关键性年份，每到此际人人反应不同
- "有如车列十字街头，有人会继续向前驶，有人却会左转或右转"
- 斗数只能指出那一年会走到十字街头，至于方向则关乎业力因果
- 实例：有人十万火急电传其子生辰，王亭之曾嘱不可拈花惹草，结果在外国染上爱滋

### 2.5 "社会人事有影响"

**王亭之注解**：
- 同一星命祸福不同，除个人业力外还有社会背景、人事关系
- 台湾人可因土地发家，大陆人亦可因土地惹祸
- 开放政策前跟外地有点小交易就变反革命，开放后迁移宫好的人可以出外发财
- **同一星系组合可以在此为吉在彼为凶**

### 2.6 "宫位实无关五行"

**王亭之批判**：
- 《全书》注文将"五行之宫位"解释为长生十二神定贵贱，"可谓陋甚"
- 赋文以下无一字跟五行有关，故"五行之宫位"实无用五行作推算准则之意
- 推断荣枯应"看宫位"而非"看五行"

### 2.7 八个夹局

王亭之系统论述了八个夹局：
1. **夹贵**（魁钺夹）
2. **夹科禄权**（为正格）
3. **夹日月**
4. **夹昌曲**
5. **夹空劫**
6. **夹羊陀**
7. **廉贞七杀的反格**
8. 天梁有刑杀之气

### 2.9 天同化不化忌？

**关键争议**：王亭之在骨髓赋注释中专门讨论了"天同化不化忌"的问题。结合《谈斗数》中的自杀案例（周刊读者天同天梁在寅申→看出自杀念头），王亭之明确支持中州派"天同可以化忌"的传承，反对闽派"天同不化忌"的说法。

### 2.10 巨门是否失陷？

王亭之在注释中讨论了巨门在辰戌是否失陷的问题，结合《谈斗数》中"辰戌应嫌陷巨门"的古歌，认为巨门在辰戌确实力量减弱，但不应一概而论为凶。

## 三、《女命骨髓赋》核心要点

### 3.1 王亭之对女命论法的修正态度

从目录可见王亭之的修正方向：
- "府相女命，持家相夫"——传统观点保留
- "廉贞清白"的意义——重新诠释
- "天同清白与相守"——重新诠释

## 四、《星曜飞躔十二宫吉凶反应的研究》核心论点

### 4.1 研究方法

**核心比喻**："星曜好似塑胶，宫位好似模型"——本质不变，外形随宫位改变。

**研究框架**：每颗星先论基本性质（庙旺落陷、百官朝拱条件、化曜影响），再逐宫论飞躔反应（命宫→兄弟→夫妻→子女→财帛→疾病→迁移→交友→事业→田宅→福德→父母）。

### 4.2 紫微星逐宫要点摘录

**命宫**：
- 百官朝拱的紫微以居命宫为最宜，居福德宫亦佳
- 独坐不得百官朝拱→必须见空曜及华盖始主好研究哲理或宗教信仰
- "紫微贪狼"见空曜及煞曜者易转化为宗教信仰
- 紫微在命宫最普遍的现象：**耳软心活、无所不好**——听信谗言是紫微最大缺点

**兄弟宫**：
- 紫微在兄弟宫见七杀羊陀火铃者，兄弟姐妹皆宜双数则不克
- 兄弟宫又用来推断同僚同学——见紫微会吉星者主有能提携自己的同学同事，但自己必须甘心处于"佐贰"地位

**夫妻宫**：
- 紫微坐夫妻宫基本性质跟辅佐煞化诸曜关系甚大
- "紫微天府"同宫未必一定白头偕老——据王亭之师传，有时亦主二婚之命
- "紫破""紫相"两种结构婚姻最难完美
- 辅佐诸曜有时亦主为第三者

**子女宫**：
- 现代社会与其用星曜性质推断长子，倒不如用来兼视主要下属或学生门徒
- 不喜欢"紫微破军""紫微天相"在子女宫——若受煞忌会照则与下属学生不和
- 紫微在子女宫以迟得为佳——不仅子女，门生弟子以及得力下属均主迟得

**财帛宫**：
- 紫微守财帛宫的富裕仅主有财可用或收入丰厚，**不主可成巨富**——紫微偏重权力名誉不是财星
- "紫微七杀""紫微破军""紫微贪狼"见煞曜亦能骤发，但蕴藏发后暴败之机
- 综合而言：不求暴发但求财源充盈能敷场面应用，反而成为最安定的性质

**疾病宫**：
- 紫微属阴土→一般主消化系统疾患
- "紫微天相"见煞→皮肤过敏或肾结石胆结石膀胱结石
- "紫微破军"往往成为患性病或暗病的基本结构
- "紫微天府"见武曲化忌+刑忌虚耗太重→严重胃病或消化器官病变出现瘤肿溃疡甚至癌症

**迁移宫**：
- 紫微在迁移宫对"七杀朝斗"格局的人不一定代表迁移有利——即使紫微得百官朝拱亦主下属众多仍主在出生地发展

### 4.3 王亭之师传口诀摘录

| 口诀 | 出处 |
|------|------|
| "紫微七杀与禄同，化杀为权逞英雄" | 师传 |
| "紫微天相辰戌宫，最喜权禄喜相逢" | 师传 |
| 紫微与天府同宫未必白头偕老，有时亦主二婚之命 | 师传 |

### 4.4 对《全书》注文的批判

- "不入庙，无左右，为孤君"→应读如"不入庙，无百官朝拱，为孤君"
- "无道之君"不同于"在野孤君"——无道主横悖刁诈，孤君仅主沦落失权
- 古诀"紫微巳亥旺地与七杀同丙戊生人财官格"→坊本作"乙戊生人"误，应为丙戊
